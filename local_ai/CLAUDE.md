# AI 영역 Claude Code 지침

이 문서는 `local_ai/` 전체에 적용된다. 작업 전에 `local_ai/README.md`, `docs/architecture/data-contracts.md`와 `evals/README.md`를 읽는다.

- AI는 VLM, 녹음 입력과 음성 형식, STT, 화자 처리, 생성 모델, 안전 필터와 평가 기준을 담당한다.
- FE 화면 구조, 데이터 저장 방식과 서버 배포 구조를 AI 작업에서 임의로 확정하지 않는다.
- 특정 모델, 임계값과 재시도 횟수는 검증 결과 없이 선택하거나 고정하지 않는다.
- 모델 변경에는 출처, 버전, 라이선스, 입력과 출력, 평가 조건, 결과와 실패 사례를 기록한다.
- 테스트 자료는 합성 데이터나 사용 권한이 확인된 자료만 사용하며 실제 사용자 자료를 커밋하지 않는다.
- 계산하거나 판정할 수 없는 값은 임의로 채우지 않고 실패 이유와 수동 전환 상태를 반환한다.
- 입출력 형식을 바꾸면 공통 데이터 계약과 영향받는 FE 및 BE 문서를 같은 변경에서 갱신한다.
- 생성 결과는 확인된 사실, 제안과 관찰값을 구분하고 의료적 해석을 추가하지 않는다.
