# AI 영역

담당 리더: 이문영

상태: 모델과 임계값은 AI 리더 검증 후 확정

## 담당 범위

- 프로필 이미지 분석 후보
- 녹음 라이브러리, 음성 파일 형식과 STT 입력 연결
- STT 모델과 실시간 및 후처리 역할
- 화자 전환과 화자 식별
- 대화 카드, 추가 질문, 리포트와 이야기 후보 생성
- 모델 입출력, 신뢰도와 실패 기준
- 금기 질문과 확인되지 않은 사실 생성 방지
- 평가 결과와 수동 전환 조건

AI는 녹음 라이브러리와 STT 연결, 모델과 품질 기준을 정한다. 앱 실행 파이프라인과 자원 처리는 BE와 공동 검토하며, FE는 합의된 녹음 인터페이스를 화면과 사용자 권한 흐름에 연결한다.

## 확정된 기준

- STT는 경량 모델을 이용한 단말 처리를 우선 검토
- 클로바 STT를 사용하지 않음
- 외부 STT와 LLM은 업체, 처리 국가, 보유기간과 자체 학습 여부가 검토된 뒤에만 도입 가능
- 외부 AI 요청에는 직접 식별정보를 포함하지 않음
- 이미지 분석 결과는 사실이 아니라 보호자 확인 후보
- 확인되지 않은 생애 사실을 생성하지 않음
- 최근 기억 확인형 질문, 의료 진단과 치료 효과 표현 금지
- 신뢰도가 부족하면 수치와 해석을 만들지 않고 수동 입력으로 전환

## AI 리더가 정할 사항

- 이미지 분석 모델과 메타데이터 사용 범위
- 녹음 라이브러리, 음성 형식과 STT 입력 조건
- STT 모델, 크기, 버전, 해시와 라이선스
- 실시간 처리와 최종 후처리의 관계
- 화자 전환과 화자 식별 방식
- 카드와 리포트 생성 모델 및 입력 문맥
- 신뢰도, 통과 기준과 재시도 상한
- 실패 시 보호자 확인과 수동 입력 조건
- 평가 지표, 테스트 자료와 실행 명령

선택 결과에는 모델 출처, 라이선스, 입력과 출력, 검증 단말, 처리 시간, 메모리, 정확도, 실패 사례와 재검토 조건을 기록한다.

## 입출력 경계

- 공통 형식은 `docs/architecture/data-contracts.md`를 초기 기준으로 사용
- 직접 식별정보와 로컬 파일 경로를 외부 요청에 포함하지 않음
- 외부 업체의 자체 모델 학습을 기능 필수 처리로 허용하지 않음
- 추정한 이야기는 확정 정보가 아니라 검토 후보로 반환
- 계산할 수 없는 값은 `null`과 이유 코드로 반환

## 실행과 평가

모델과 평가 스크립트가 병합된 첫 PR에서 실제로 검증한 명령을 기록한다. 현재는 명령과 성능 수치를 임의로 작성하지 않는다.
