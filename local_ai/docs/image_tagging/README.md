## 현재까지 확인된 내용

- 작은 온디바이스 VLM 후보는 사진의 맥락을 대화와 스토리에 쓸 수준으로 표현하는 데 한계가 있었다.
- 단순 태그만으로는 인물 관계, 상황과 대화 단서를 충분히 전달하기 어렵다.
- 사진 메타데이터는 스캔, 재촬영, 편집과 전달 과정에서 원래 촬영 정보와 달라질 수 있다.
- 메타데이터와 모델 출력은 확정 사실이 아니며 보호자 확인 전 프로필이나 스토리에 반영하지 않는다.
- 모델 비교 결과는 측정 환경과 입력에 한정된 근거이며 제품의 최종 모델 결정을 대신하지 않는다.

## 문서 경계

- 비교 요약에는 입력, 모델, 프롬프트, 핵심 결과, 실패 유형과 한계를 남긴다.
- 이미지별 전체 출력은 근거 문서에만 둔다.
- 원본 이미지와 실제 사용자 자료는 저장소에 추가하지 않는다.
- 제품 결정은 AI README와 ADR에서 관리하고 이 폴더에는 실험 결과만 기록한다.
