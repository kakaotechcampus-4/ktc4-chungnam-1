# 이미지 17종 Haiku 4.5와 Luna low 비교

실행일: 2026-09-14

## 결론

현재 프롬프트와 구독형 CLI 실행 환경에서는 Luna low가 더 안정적이었다.

- Luna low는 17장 모두 3개에서 5개의 키워드를 유효한 JSON으로 반환했다.
- Haiku 4.5 low는 17장 중 15장만 출력 계약을 지켰다. 한 장은 JSON 키에 따옴표가 없었고, 한 장은 설명문과 빈 배열을 반환했다.
- 평균 벽시계 시간은 Luna 7.13초, Haiku 24.74초였다. Luna가 약 3.47배 빨랐다.
- API 정가 환산액은 Luna 전체 0.0508402달러, Haiku 전체 0.5003468달러였다. 이번 CLI 측정에서는 Luna가 약 9.84배 저렴했다.
- 수동 검토에서 Luna는 A 10장, B 7장, C 0장이었다. Haiku는 A 2장, B 9장, C 6장이었다.
- 두 모델 모두 사진에 없는 그럴듯한 소품과 상황을 섞었다. 결과는 확인된 사실이 아니라 보호자가 검토할 대화 소재 후보로 사용해야 한다.

등급은 이번 17장에 대한 수동 판정이다. A는 핵심 장면을 대체로 정확하고 구체적으로 잡은 출력, B는 쓸 만한 단어와 확인하기 어려운 추정이 섞인 출력, C는 핵심 오인, 명확한 환각 또는 출력 계약 실패가 있는 출력이다. 기존 보고서의 Claude Opus 5 Description은 사진 확인을 돕는 참조 설명으로만 사용했고 정답으로 간주하지 않았다.

사이트의 기존 프롬프트를 그대로 사용하고, 결과를 기계적으로 검사하기 위해 JSON 객체만 출력하라는 형식 지시를 뒤에 붙였다.

```text
이 사진에서 그 시절의 일상 생활, 일거리, 도구, 음식 등 이야기 소재가 될 수 있는 구체적인 옛 추억 단어 키워드 3~5개를 JSON으로 출력해줘. (예: 연탄불, 재봉틀, 국민학교 도시락 등 일상 소재 / 사람, 건물, 풍경 같은 단순 일반명사는 제외)

반드시 다음 형식의 JSON 객체만 출력하고 다른 설명은 쓰지 마세요.
{"topics":["키워드1","키워드2","키워드3"]}
```

프롬프트 SHA-256은 `9746307bb7b46fa901419b97e358eff5f5e14ca00648141dda67e9ee1448ffd6`이다. 사용한 이미지는 기존 보고서의 `target-image/`에 있는 공개 이미지 17장이다.

Haiku가 반환한 코드 펜스는 제거한 뒤 JSON을 검사했다. 따라서 출력 계약 준수 15건은 코드 펜스를 허용한 파서 기준이다. 따옴표 없는 키와 JSON 밖 설명문은 실패로 분류했다. Luna는 출력 스키마를 CLI에 직접 적용했다.

Haiku는 Claude Code가 보고한 `costUSD`와 `costBasis: list` 값을 합산했다. Luna는 공식 모델 페이지의 입력 100만 토큰당 0.20달러, 캐시 입력 0.02달러, 출력 1.20달러를 적용했다. Luna의 추론 토큰은 출력 토큰에 포함되므로 중복 과금하지 않았다.

이번 호출은 Claude.ai Max와 Codex 구독 세션에서 실행했다. 위 금액은 카드에 추가 청구된 실제 금액이 아니라, CLI가 기록한 토큰을 API 정가로 환산한 비교값이다. 토큰에는 이미지 내용 외에도 각 CLI의 시스템 지시와 도구 사용 문맥이 포함된다. 두 CLI의 이미지 전달 경로가 다르므로 순수 모델 API 벤치마크로 일반화하면 안 된다.

## 확인된 실패 유형

### Haiku

- 1980년대 올림픽 개막식 고싸움 장면을 호루라기와 말고삐로 잘못 읽었다.
- 월드컵 항공 사진에서 공중전화, 손수건과 호떡처럼 보이지 않는 물건을 만들었다.
- 광장시장 빈대떡을 호떡과 붕어빵으로 오인했다.
- 차례상 도해를 실제 상차림으로 읽고 다리미까지 생성했다.
- 2023년 사진은 옛 추억에 맞지 않는다고 판단해 키워드 생성을 거부했다. 사용자의 3개에서 5개 조건과 JSON 전용 조건도 어겼다.
- 한 출력은 `{topics:[...]}` 형태여서 엄격한 JSON이 아니었다.

### Luna

- 장면 종류는 대체로 맞췄지만, 사진에서 직접 확인할 수 없는 회수권, 새참, 페이스페인팅, 휴대폰 문자중계와 보자기 간식 등을 섞었다.
- 올림픽 고싸움 장면을 풍물놀이로 좁혀 읽어 핵심인 굵은 동아줄과 줄다리기를 놓쳤다.
- 차례상 도해를 실제 상차림으로 읽었다.
- 월드컵 항공 사진처럼 개별 소품을 식별하기 어려운 이미지에서도 구체적인 소품을 자신 있게 만들었다.

## 적용 제안

1. 1차 후보 생성은 Luna low로 진행할 수 있다.
2. 출력은 사실이 아니라 `AI 제안` 상태로 저장한다.
3. 사진에서 직접 관찰한 내용과 대화를 확장하기 위한 연상어를 필드로 분리한다.
4. 보호자가 확인, 수정 또는 거절한 뒤에만 카드와 스토리에 반영한다.
5. 프롬프트에 사진에서 직접 보이는 근거가 없는 단어는 `inferred`로 표시하라는 규칙을 추가한다.
6. 출력 JSON에 `keyword`, `evidence`, `confidence`, `type` 필드를 두고 `type`은 `observed`와 `inferred`로 제한한 후 다시 비교한다.
7. 차례상 도해, 항공 사진, 행사 사진처럼 오인이 반복된 유형을 실패 회귀 테스트로 유지한다.

이번 결과만으로 최종 모델을 선정하지 않는다. 다음 실험에서는 태그가 아니라 문맥형 사진 설명과 대화 질문 후보를 생성하고, 사실과 추정을 분리할 수 있는지 확인해야 한다.

## 제외한 사전 점검

공식 34회 전에 CLI와 이미지 입력을 확인하는 사전 점검이 있었다. 아래 성공 호출은 공식 통계에서 제외했다.

- Haiku 1회: 확인 가능한 API 정가 환산액 0.037066달러
- Luna 1회: 확인 가능한 API 정가 환산액 약 0.0033794달러

Claude의 JSON 스키마 인수 오류 2회는 모델 호출 전에 실패했다. 추가 Haiku 점검 1회는 실행 상태를 확정할 자료가 없어 비용 합산에서 제외했다. 따라서 사전 점검까지 포함한 실제 API 환산 총액을 단정하지 않는다.
