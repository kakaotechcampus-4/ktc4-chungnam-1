# 화면 디자인 기준

새록 앱의 화면을 만들 때 따르는 기준이다. 기술 선택은 [`README.md`](README.md), 개발 환경은 [`SETUP.md`](SETUP.md)에 있다.

피그마 시안은 참고 자료다. 구도와 담을 내용은 시안을 따르고, 색과 간격과 컴포넌트는 이 문서를 따른다. 시안은 세 사람이 나눠 그려 형식이 통일되어 있지 않다.

<br>

## 원칙

- **한 화면에 한 가지 일.** 주 사용자는 50~60대 보호자다. 화면을 열었을 때 무엇을 해야 하는지 한 번에 보여야 한다.
- **흑백과 포인트 색 하나.** 색으로 꾸미지 않는다. 색은 상태와 강조에만 쓴다.
- **주 행동은 검정 버튼 하나.** 화면마다 가장 중요한 행동을 검정 버튼으로 두고, 나머지는 그보다 약하게 만든다.
- **디자인 요소는 더해도 되지만 기능은 더하지 않는다.** 화면에 없던 버튼, 입력, 단계를 만들지 않는다.
- **미정 항목을 화면으로 확정하지 않는다.** 카드 수, 자동 선택, 추가 대화 방식은 PM 문서의 검토 중 항목이다.

<br>

## 색

포인트 색은 `assets/images/`의 이미지에서 뽑은 세이지 그린이다. 이미지가 화면의 큰 면적을 차지하므로 색을 이미지에 맞췄다.

### 기본

| 용도 | 값 | 흰 배경 대비 |
| --- | --- | --- |
| 본문 글자, 주 버튼 면 | `#111111` | 18.9 : 1 |
| 보조 글자 | `#5C5C5C` | 6.7 : 1 |
| 비활성 글자 | `#767676` | 4.5 : 1 |
| 구분선, 테두리 | `#E0E0E0` | — |
| 표면, 카드 배경 | `#F5F5F5` | — |
| 화면 배경 | `#FFFFFF` | — |

`#9E9E9E`보다 연한 회색은 글자에 쓰지 않는다. 흰 배경에서 대비가 4.5:1에 못 미친다.

### 포인트 (세이지 그린)

| 용도 | 값 | 비고 |
| --- | --- | --- |
| 가장 연한 면 | `#E9F5DC` | 배너, 강조 영역 배경 |
| 연한 면 | `#D7E8C3` | 칩, 선택 상태, 진행 표시 |
| 테두리, 선택 윤곽 | `#C0D6A7` | |
| 글자와 아이콘 | `#5E7347` | 흰 배경 대비 5.2 : 1 |
| 진한 글자 | `#4E6138` | 흰 배경 대비 6.8 : 1 |

**연한 면 위에는 검정 글자를 올린다.** `#D7E8C3` 위의 `#111111`은 14.6:1로 잘 읽히지만, 같은 면 위의 `#5E7347`은 4.0:1이라 작은 글자에는 쓰지 않는다.

포인트 색으로 주 버튼을 만들지 않는다. 주 버튼은 검정이다.

### 경고

| 용도 | 값 | 흰 배경 대비 |
| --- | --- | --- |
| 오류 글자와 아이콘 | `#99392E` | 7.1 : 1 |
| 오류 영역 배경 | `#F7E9E7` | 그 위엔 `#99392E` 글자 |

흙빛이 도는 붉은색이다. 이미지의 따뜻한 톤과 부딪히지 않으면서 경고로 읽힌다.

<br>

## 글자

50~60대가 주 사용자다. 본문을 17로 두고, 그보다 작은 글자는 보조 정보에만 쓴다.

| 역할 | 크기 | 굵기 |
| --- | --- | --- |
| 화면 제목 | 28 | 700 |
| 섹션 제목 | 20 | 700 |
| 본문 | 17 | 400 |
| 본문 강조 | 17 | 600 |
| 보조 | 15 | 400 |
| 캡션 | 13 | 400 |
| 버튼 | 18 | 600 |

- 캡션 13이 가장 작은 글자다. 그보다 작게 쓰지 않는다.
- 줄 간격은 글자 크기의 1.5배를 기본으로 한다.
- 한 줄에 담기지 않는 문장은 줄여 쓰기(`...`)보다 두 줄로 보여준다. 어르신 이름과 날짜처럼 잘리면 뜻이 사라지는 값은 특히 그렇다.

<br>

## 간격과 모양

- 간격은 **4의 배수**만 쓴다. `4 8 12 16 20 24 32 40 48`
- 화면 좌우 여백은 **20**이다.
- 섹션 사이는 **32**, 같은 섹션 안의 항목 사이는 **12**를 기본으로 한다.

| 요소 | 모서리 |
| --- | --- |
| 버튼 | 14 |
| 카드, 입력 상자 | 16 |
| 칩, 뱃지 | 완전한 둥근 모양 |
| 이미지 | 16 |

### 그림자

떠 있는 느낌이 필요한 곳에만 옅게 쓴다. 카드마다 다 넣지 않는다.

| 단계 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 낮음 | `0 2 8 rgba(0,0,0,0.06)` | 목록 카드, 대화 카드 |
| 높음 | `0 4 16 rgba(0,0,0,0.08)` | 팝업 메뉴, 하단 탭바 |

<br>

## 공통 컴포넌트

| 이름 | 규칙 |
| --- | --- |
| 주 버튼 | 검정 면에 흰 글자. 높이 56. 화면당 하나 |
| 보조 버튼 | 흰 면에 `#E0E0E0` 테두리, 검정 글자. 높이 56 |
| 글자 버튼 | 면 없이 `#5E7347` 글자 |
| 상단바 | 뒤로가기와 제목. 높이 56 |
| 하단 탭바 | 일대기, 홈, 마이페이지. 높이 64. 그림자 높음 |
| 카드 | 흰 면, 모서리 16, 그림자 낮음, 안쪽 여백 16 |
| 입력 상자 | 높이 56, 테두리 `#E0E0E0`, 초점이 가면 `#5E7347` |
| 칩 | `#D7E8C3` 면에 검정 글자. 선택 안 된 상태는 `#F5F5F5` |
| 빈 상태 | 그림과 한 줄 안내. 다음에 할 일을 알려주는 버튼을 함께 둔다 |
| 로딩 | 화면 가운데 원형 표시와 한 줄 안내 |
| 준비 중 | "화면 설계 중입니다" 안내. 보류 화면에서 쓴다 |

버튼과 탭처럼 누르는 요소는 **최소 48 x 48**을 확보한다. 주 버튼은 56으로 둔다.

## 이미지

| 파일 | 쓰는 곳 |
| --- | --- |
| `logo.webp` | 스플래시 (A-1) |
| `onboarding.webp` | 처음 오셨네요 (B-1) |
| `main.webp` | 홈 |
| `patient.webp` | 프로필 설정 상단 원형 사진 |
| `family.webp` | 세부 정보 입력에서 첨부하는 가족 사진 |
| `visitation.webp` | 면회 인증샷 |

- 모두 `app/assets/images/`에 두고 `pubspec.yaml`에 선언한다.
- 형식은 **WebP**를 쓴다. 파일 이름은 영문 소문자와 하이픈만 쓴다.
- 화면 폭 전체로 쓰는 이미지는 **1236px**까지 만든다. 그보다 크게 만들지 않는다.
- **실제 사람의 사진을 쓰지 않는다.** 저장소 전체 규칙이다.
- 사용자가 앱에서 직접 넣는 사진은 이미지 자산이 아니다. 목 데이터에는 실제 파일이 없으므로 위 이미지로 자리를 채운다.

<br>

## 움직임

- **로딩 표시만 움직인다.** 그 밖의 장식 애니메이션을 넣지 않는다.
- 화면 전환은 Flutter와 안드로이드의 기본 동작을 그대로 둔다. 어느 방향으로 이동했는지 알려주는 단서라서 남긴다.
- 버튼을 누르는 순간의 기본 반응은 남긴다.

<br>

## 접근성

- 기준 화면은 412 x 917 dp 세로다. 고정 좌표에 의존하지 않는다.
- 시스템 글자 크기를 키워도 글자가 잘리거나 겹치지 않아야 한다. 높이를 고정한 상자 안에 긴 글을 넣지 않는다.
- 글자와 배경의 대비는 **4.5:1 이상**을 지킨다. 이 문서의 색 표에 값이 적혀 있다.
- 색만으로 상태를 알리지 않는다. 선택, 오류, 완료는 글자나 아이콘을 함께 쓴다.
- 화면 변경은 `README.md`에 적힌 기준 크기에서 확인하고 실제 결과를 남긴다.
