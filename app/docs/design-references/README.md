# 디자인 레퍼런스

전면 재디자인에 참고할 UI, UX 자료를 모아 둔 곳이다. 여기서 정리한 내용이
[`app/DESIGN.md`](../../DESIGN.md)의 개정안 재료가 된다.

이 폴더는 **재료**고 DESIGN.md가 **기준**이다. 화면을 만들 때는 DESIGN.md를 따르고
이 폴더를 직접 보고 따라 그리지 않는다.

<br>

## 레퍼런스 목록

| 파일 | 가져올 것 | 가져오지 않을 것 |
| --- | --- | --- |
| | | | |

### 칸 설명

- **가져올 것** — 참고할 부분을 구체적으로 적는다.
- **가져오지 않을 것** — **이 칸을 비우지 않는다.** 비어 있으면 화면 전체를 따라 그리게 되고, 레퍼런스마다 다른 방향으로 끌려간다.
