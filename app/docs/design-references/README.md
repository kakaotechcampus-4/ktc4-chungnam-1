# 디자인 레퍼런스

전면 재디자인에 참고할 UI, UX 자료를 모아 둔 곳이다. 여기서 정리한 내용이
[`app/DESIGN.md`](../../DESIGN.md)의 개정안 재료가 된다.

이 폴더는 **재료**고 DESIGN.md가 **기준**이다. 화면을 만들 때는 DESIGN.md를 따르고
이 폴더를 직접 보고 따라 그리지 않는다.

<br>

## 넣는 방법

1. 이미지를 `NN-주제-출처.png` 형식으로 넣는다. 번호는 두 자리로 붙인다.
   - 예: `01-cards-list-linear.png`, `02-form-notion.png`
   - 파일 이름은 영문 소문자와 하이픈만 쓴다.
2. 아래 표에 한 줄 추가한다.
3. 스크린샷에 실제 사람의 이름, 얼굴, 연락처 같은 개인정보가 있으면 가리고 넣는다.
   저장소 전체 규칙이다.

<br>

## 레퍼런스 목록

| 파일 | 출처 | 가져올 것 | 가져오지 않을 것 | 적용 화면 |
| --- | --- | --- | --- | --- |
| | | | | |

### 칸 설명

- **출처** — 앱이나 서비스 이름. 사이트에서 가져왔으면 주소까지 적는다.
- **가져올 것** — 참고할 부분만 구체적으로 적는다. "이 화면 참고"처럼 쓰지 않는다.
  - 좋은 예: `카드 사이 여백과 제목·부제 크기 차이`
  - 나쁜 예: `전체적인 느낌`
- **가져오지 않을 것** — **이 칸을 비우지 않는다.** 비어 있으면 화면 전체를 따라
  그리게 되고, 레퍼런스마다 다른 방향으로 끌려간다.
- **적용 화면** — 이 레퍼런스가 영향을 주는 화면. 여러 개면 쉼표로 나눈다.

<br>

## 충돌 정리

레퍼런스끼리 어긋나는 부분을 여기 적는다. DESIGN.md를 고쳐 쓸 때 먼저 결정해야
하는 항목이다.

| 항목 | 어긋나는 레퍼런스 | 결정 | 정한 사람 |
| --- | --- | --- | --- |
| | | | |

결정하지 못한 항목은 `결정` 칸을 비워 두고, 그 상태로 DESIGN.md에 반영하지 않는다.
