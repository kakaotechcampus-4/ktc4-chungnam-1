# FE 영역 Codex 지침

이 문서는 `app/` 전체에 적용된다. 작업 전에 `app/README.md`를 읽고, AI 또는 BE 연동이 있으면 `docs/architecture/data-contracts.md`도 확인한다.

- FE는 화면, 탐색, 화면 상태, 접근성, 권한 안내와 합의된 인터페이스의 앱 연동을 담당한다.
- 데이터 저장 구조와 DB 선택, 녹음 파일 형식, STT와 모델 선택을 FE 작업에서 임의로 확정하지 않는다.
- 녹음 기능은 AI가 정의한 입력 인터페이스를 사용하고, 데이터 저장과 서버 통신은 BE 계약을 따른다.
- 목업 데이터도 공통 데이터 계약과 같은 필드 및 상태값을 사용한다.
- 로딩, 권한 거부, 빈 결과, 분석 실패와 수동 전환 화면을 성공 화면과 함께 처리한다.
- 기술 선택이나 화면 기준이 바뀌면 `app/README.md`를 같은 변경에서 갱신한다.
- 화면 변경은 README에 기록된 기준 크기와 접근성 조건에서 확인하고 실제 결과를 남긴다.
