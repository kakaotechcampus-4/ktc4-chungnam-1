## 로컬 설치 환경에서 CLI로 적용하는 경우
Docker를 쓰지 않고 PC에 직접 PostgreSQL을 설치해서 사용할 경우 터미널이나 DB 관리 툴을 이용해 수동으로 init.sql을 실행해야 한다. 
```
psql -U [사용자이름] -d [데이터베이스이름] -h localhost -p 5432 -f 경로/to/init.sql
```
- 예시: `psql -U postgres -d mydb -f ./init.sql`
- 실행 후 비밀번호를 입력하면 파일 내부의 쿼리가 순서대로 실행된다.



## GUI 툴 사용 (DBeaver 등)
- DBeaver나 pgAdmin 등의 데이터베이스 툴을 실행하고 로컬 PostgreSQL 서버에 연결한다.
- 대상 데이터베이스를 선택한 뒤, 상단 메뉴에서 [파일] -> [SQL 스크립트 열기]를 통해 `init.sql`을 불러온다.
