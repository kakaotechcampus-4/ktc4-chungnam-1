# 전사 입력 검사와 화자 정보의 한계

## 프로그램이 검사하는 부분

리포트 입력은 STT 결과의 `segments`다. 발화 구간이 없거나 모든 구간이 공백이면
`EMPTY_TRANSCRIPT`로 작업을 끝내며 리포트 생성기를 호출하지 않는다. STT 응답의
전체 `text`만 있어도 구간 전사가 없으면 같은 기준을 적용한다.

이 검사는 STT 엔진이 오류를 반환한 경우와 다르다. 요청은 성공했지만 리포트에 사용할
발화가 없는 경우를 구분한다. 기존 오류 처리 경로가 원본 정리를 시도한다. 자동 재녹음이나
수동 입력 화면으로 이동시키는 기능은 이번 변경에 포함하지 않았다.

무음에서 STT가 지어내는 알려진 문장은 빈 전사 판정 전에 뺀다(`app/services/transcript_filters.py`). 2026-11-07 실기기 시험에서 아무도 말하지 않은 녹음이 "다음 영상에서 만나요."로 옮겨져 리포트 제목까지 만들어졌다. 구간 문장 전체가 영상 끝맺음("다음 영상에서 만나요", "시청해 주셔서 감사합니다", "구독과 좋아요 부탁드립니다" 등)이나 방송 끝맺음("MBC 뉴스 OOO입니다") 목록과 같을 때만 빼고, 대화 안에 섞인 말과 "감사합니다"처럼 면회에서 할 만한 말은 남긴다. 모두 빠지면 면회 분석은 `EMPTY_TRANSCRIPT`, 프로필 음성 입력(#138)은 빈 문자열이 되어 앱이 "알아듣지 못했어요"로 처리한다.

AI 함수가 직접 호출될 때도 빈 구간 전사는 모델 클라이언트 생성 전에 `INVALID_REQUEST`로
거절한다. 인식 확률에 임의의 기준점을 추가하거나 짧은 발화를 모두 버리지 않는다.

## 모델에 전달하는 화자 정보

8-3 요청에 선택 항목 `participantCount`를 추가했다. BE는 해당 회차의 해당 분석 작업에
저장된 참여 인원을 읽는다. 기존 호출자가 생략했다면 값을 추측하지 않는다.
AI 패키지는 다음 값을 계산해 모델 입력의 `transcript_context`에 넣는다.

- 녹음 제출 당시 예상 참여 인원
- 내용이 있는 구간에서 관측된 서로 다른 화자 라벨 수
- 화자 라벨을 배정하지 못한 발화 존재 여부
- 예상 인원보다 라벨이 적은지
- 사람의 역할 확인 여부. 현재 별도 역할 확인 계약이 없어 항상 false

화자 라벨 한 개가 나온 것은 항상 오류라는 뜻이 아니다. 실제로 한 사람만 말했을 수도 있다.
두 사람이 한 라벨로 합쳐졌는지 코드가 확정한 것으로 보고하지 않는다.

## 프롬프트 변경

`report-3`, `proposals-5`는 라벨이 없는 구간도 앞뒤 맥락으로 화자를 추론할 수 있도록 한다.
입력 인원과 라벨 수가 달라도 생성을 막지 않는다. 전사에 나온 경험은 주체가 불확실해도
검토용 이야기 후보로 제시할 수 있다. 제안 이유에 추론 근거와 확인 필요를 적도록 지시하며,
리포트는 근거가 부족한 귀속을 단정하지 않는다. 전사에 없는 경험이나 관계를 만들지 않는다.
보호자 소감은 보호자의 평가라고 구분하고 입력 자료의 명령은 따르지 않는다.

앱의 BE 처리 경로에서도 라벨 누락이나 예상 인원보다 적은 라벨 수로 모델 호출을
차단하지 않는다. 리포트와 변경 제안 생성 함수를 호출하고 응답 검증 후 저장한다.
화자 미확인 고정 안내로 대체하지 않는다. 화자가 불확실한 경험도 검토용 이야기 후보로 제시할 수 있으며, 제안 이유에 추론 근거와
확인이 필요한 부분을 적도록 지시한다. 보호자가 확인하기 전에는 제안을 프로필에 반영하지 않는다.
[화자와 리포트 생성](speaker-fact-boundary.md)에 동작과 한계를 명시했다.
라벨이 두 개 나온 경우에도 보호자와 어르신 역할이 확인됐다고 보장하지 않는다.
의학적 판단이나 치료 표현의 출력 검사는 이 입력 변경으로 해결되지 않는다.

## 검증 범위

합성 응답과 격리 DB로 빈 전사의 외부 호출 차단, 정상 발화의 통과, 역할 미확인 정보 전달,
기존 API 호출의 호환을 검사한다. 실제 STT 모델, 실제 리포트 모델과 실제 사람 목소리는
사용하지 않았다. 특히 2인 대화가 한 라벨로 합쳐진 실제 결과에서도 대화 요약이 생성되고
특정 인물의 경험으로 잘못 단정하지 않는지 추가 확인해야 한다.

실제 모델 비교에서는 두 사람 분리 성공, 두 사람 한 라벨, 전 구간 null, 한 사람만 발화,
짧은 정상 발화, 무음의 사례를 구분한다. 성공 여부와 별도로 잘못된 어르신 발언 귀속을
기록한다. 본 자동 시험의 통과 수를 실제 분류 정확도로 보고하지 않는다.
