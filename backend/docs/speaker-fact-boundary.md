# 화자 라벨과 리포트 생성

화자 라벨 누락(null·빈 문자열 포함)이나 입력 인원보다 적은 라벨 수를 이유로 리포트 생성을 차단하지 않는다. 리포트와 변경 제안 생성 함수를 호출하고 응답 검증 후 저장한다. 고정된 화자 미확인 안내로 대체하지 않는다.

- 발화가 전혀 없는 전사는 `EMPTY_TRANSCRIPT`로 실패한다.
- 의료 효과 표현 검사, 카드와 제안의 응답 검증, 시간 제한과 작업 임대 확인은 유지한다.
- 라벨은 실제 인물 역할의 증명이 아니다. 대화 맥락으로 화자와 경험의 주체를 추론하며, 불확실한 이야기 후보는 제안 이유에 확인이 필요하다고 적도록 지시한다.
- AI 제안은 보호자 확인 없이 프로필과 스토리북에 반영하지 않는다.
- 완료 시 전사 삭제 정책은 유지하며, 이미 완료된 안내 리포트를 자동 재생성하지 않는다.

`tests/test_speaker_fact_boundary.py`는 합성 전사와 모델 대역으로 라벨 누락 및 인원 차이에도 두 생성 함수가 호출되고 결과가 저장되는지 검사한다. 빈 전사와 임대 만료도 검사한다. 실제 모델과 운영 자료의 품질 검증은 별도다.
