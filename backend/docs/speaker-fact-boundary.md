# 화자 구분이 부족한 전사의 새 이야기 저장 검사

로컬 보완안이다. 실제 모델과 운영 자료로 검증하지 않았으며 GitHub와 운영에 반영하지 않았다.

- 발화가 있는 구간의 라벨만 검사한다. 빈 라벨과 null 라벨을 화자 확인으로 세지 않는다.
- 미확인 발화가 있거나 라벨 수가 입력 인원보다 적으면 AI에 새 이야기 후보를 빈 배열로 반환하도록 전달한다.
- 이 조건에서 AI가 새 이야기 후보를 반환하면 BE가 `UNVERIFIED_SPEAKER_FACT`로 응답 전체의 저장을 거절한다. 일부 후보만 안전하다고 임의로 고르지 않는다.
- 후보가 없으면 대화 주제와 보호자 소감을 정리한 리포트는 저장할 수 있다. 화자 하나라는 이유로 모든 리포트를 차단하지 않는다.
- 한 명 입력에 한 라벨이 나온 경우는 허용한다. 라벨 수가 맞아도 보호자와 어르신의 역할이 확인된 것은 아니다. 프롬프트의 출처 구분과 보호자의 이야기 승인 절차는 계속 필요하다.

한 참여자가 말하지 않은 경우에도 라벨은 입력 인원보다 적을 수 있다. 이 검사는 화자 분리 모델의 실패를 확정하는 기준이 아니며, 새 생애 이야기의 자동 제안을 보수적으로 제한한다. 현재 응답에는 후보별 근거 발화 연결이 없어 미확인 구간을 쓰지 않은 후보만 따로 살릴 수 없다. 이 제한은 PR에서 AI 담당자가 검토해야 한다.

리포트 문장 전체의 인물 지칭을 프로그램이 검증하는 기능은 아니다. 실제 모델이 화자 불확실성을 올바르게 설명하는지 평가가 필요하다. `UNVERIFIED_SPEAKER_FACT`로 실패하면 기존 수동 재처리 경로에서 남아 있는 전사를 다시 사용하며 보관 기한을 연장하지 않는다.
