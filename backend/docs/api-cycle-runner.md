# 배포 후 합성 자료로 API 연결 검사

`scripts/verify_api_cycle.py`는 배포한 API에 합성 녹음을 보내 두 번째 면회 시작까지 확인하는 도구다. 이번 개발에서는 실제 서버에 실행하지 않았다. 기본 실행은 검사 순서만 출력하고 네트워크 요청을 보내지 않는다.

```powershell
uv run --locked python scripts/verify_api_cycle.py
```

## 실행 전에 준비할 것

- **전용 시험 계정**의 유효한 세션 토큰과 계정 UUID. 계정을 자동 생성하거나 동의 값을 바꾸지 않는다. 토큰은 저장소 밖의 파일에 두고 저장소, 명령 인수나 결과 로그에 값을 넣지 않는다.
- 실제 사람의 기록이 아닌 **합성 대화 녹음**. WAV, 16kHz, 16-bit, mono, 최대 15분, 32MiB 이하다. 무음 파일은 업로드 형식만 통과할 수 있으며 리포트 성공용 자료가 아니다.
- 음성 업로드, STT, 실제 AI 호출과 비용 발생이 승인된 시험 환경. 녹음의 참여 인원을 `--participant-count`에 맞춘다. 화자가 부족하다고 새 이야기 후보를 강제로 만들지 않는다.
- 배포 API와 worker, DB migration의 버전. 옛 앱 호환 검사와 이 스크립트는 별도다.

PowerShell에서 아래 환경 변수에 승인받은 시험 환경과 로컬 파일 경로를 지정한 뒤 실행한다. 값이 없으면 실행 준비가 끝난 것이 아니다.

```powershell
uv run --locked python scripts/verify_api_cycle.py `
  --base-url $env:SAELOG_TEST_API_URL `
  --token-file $env:SAELOG_TEST_TOKEN_FILE `
  --test-account-id $env:SAELOG_TEST_ACCOUNT_ID `
  --synthetic-wav $env:SAELOG_SYNTHETIC_WAV_FILE `
  --participant-count 2 `
  --execute-synthetic-test --allow-remote
```

원격 주소는 HTTPS와 `--allow-remote`를 모두 요구한다. URL에 인증정보, 쿼리와 경로를 넣지 않는다. 리다이렉트를 따라가지 않으며 환경 변수의 HTTP 프록시를 자동 사용하지 않는다. `GET /auth/me`의 계정과 명시한 시험 계정이 다르거나 필수 동의가 없으면 변경 요청을 보내지 않는다.

`--execute-synthetic-test`는 새로 만든 합성 프로필의 후보를 시험 목적으로 승인하고 수정한다는 뜻이다. 기존 프로필을 입력받지 않으며 실제 사용자 이야기를 승인하는 용도로 사용하지 않는다. 새 프로필을 계속 만들면 프로필 한도에 닿을 수 있다. 시험 자료도 자동 삭제하지 않으므로 출력된 자원 ID를 확인해 별도 승인 후 정리한다.

## 검사 흐름

1. 합성 프로필을 만들고 첫 카드 12장을 생성한다.
2. 두 카드를 선택해 첫 면회를 만들고 소감과 합성 녹음을 제출한다. 한 카드는 사용, 다른 카드는 미사용으로 기록한다.
3. 전사와 리포트 처리가 끝날 때까지 상태를 조회한다. 리포트를 다시 읽어 같은 응답인지 확인한다.
4. 새 이야기 후보가 일대기에 미리 저장되지 않았는지 확인한다. 시험 프로필의 첫 후보만 승인하고 나머지 후보는 거절한다. 주제 제안이 있으면 시험 선택으로 제외한다. 미사용이라는 이유로 제외했다고 해석하지 않는다.
5. 승인한 내용이 저장됐는지 확인하고 다음 카드 12장을 만든다. 제외한 주제 ID가 다시 들어오지 않아야 한다.
6. 저장한 합성 이야기를 수정한다. 다음 카드에 `needsRefresh`가 붙고 정정 전 카드로 면회 시작이 거절되는지 검사한다.
7. 카드 12장을 갱신한 뒤 두 번째 면회를 시작한다. 이전 카드 묶음과 회차 ID를 재사용하지 않아야 한다.

## 결과와 한계

- 성공은 `passed_api_flow`, 미완료는 `incomplete`이며 종료 코드 1이다. 실패한 변경 요청을 자동 재제출하지 않는다.
- 이야기 후보가 없으면 `NO_STORY_CANDIDATE_CYCLE_NOT_VERIFIED`로 끝낸다. 임의 이야기를 직접 넣어 성공으로 바꾸지 않는다. 후보가 없다는 것이 항상 제품 오류라는 뜻도 아니다.
- 주제 제안이 없으면 `topicExclusionChecked=false`로 남긴다. 검사하지 않은 제외 처리를 통과로 보고하지 않는다.
- 결과에는 단계, 소요 시간, 이 실행에서 만든 자원 ID만 담는다. 토큰, 전사문, 생성된 문장과 파일 경로는 출력하지 않는다.
- 공개 API로는 모델에 전달한 전체 입력이나 문장 의미를 검증할 수 없다. 승인된 모든 이야기가 카드 문구에 나와야 한다고 요구하지 않는다. 실제 출력에서 정정 전 사실의 재사용과 잘못된 인물 귀속을 사람이 따로 확인한다. 최신 입력 전달은 `test_second_visit_flow.py`에서 생성 함수 인수로 검사한다.
- 두 번째 면회는 **시작까지만** 확인한다. 두 번째 녹음과 리포트, Android 화면, 실제 마이크, 화면 잠금과 강제 종료를 확인하는 도구는 아니다.
- 각 생성 작업의 폴링 기본 제한은 1,200초이며 `--wait-seconds`로 1~3,600초 범위에서 바꾼다. 개별 HTTP 요청은 최대 30초 대기하므로 마지막 요청까지 그 시간만큼 더 걸릴 수 있다. 전체 제품의 처리 시간 약속이 아니다.

## 로컬 검사

`tests/test_api_cycle_runner.py`는 계획 모드 무접속, 계정 불일치, 동의 없음, 리다이렉트, 시간 초과, 작업 실패, 후보 없음과 제외 위반을 검사한다. 별도 사례는 실제 FastAPI 라우터와 임시 PostgreSQL, worker를 연결하고 외부 모델 및 S3만 합성 응답으로 대신한다.

```powershell
uv run --locked pytest tests/test_api_cycle_runner.py tests/test_second_visit_flow.py -ra
```

DB 사례에는 생성과 삭제가 허용된 전용 `SAEROK_TEST_DATABASE_URL`이 필요하다. 운영 DB를 지정하지 않는다. 이번 통과 기록은 실제 배포 서버나 모델의 성공 기록이 아니다.
