# BE 영역 Codex 지침

이 문서는 `backend/` 전체에 적용된다. 작업 전에 `backend/README.md`와 `docs/architecture/data-contracts.md`를 읽고, 데이터 이동이 있으면 `docs/legal/README.md`도 확인한다.

- BE는 데이터 저장과 이동, API, 인증, 로그, 임시 파일 삭제와 모델 실행 연동을 담당한다.
- AI 모델과 품질 기준, FE 화면 동작과 제품 범위를 BE 작업에서 임의로 확정하지 않는다.
- 요청과 응답은 공통 데이터 계약을 따르고 입력 검증, 권한 확인과 명시적인 오류를 제공한다.
- 사용자 원문과 식별정보를 로그, 예외 메시지와 분석 도구에 남기지 않는다.
- 데이터 계약을 바꾸면 영향받는 FE와 AI 담당자에게 알리고 계약 문서를 같은 변경에서 갱신한다.
- 외부 서비스, 새로운 저장 위치와 데이터 이동 경로를 도입할 때는 README, ADR과 법률 문서를 먼저 갱신한다.
- 실패를 성공으로 처리하는 숨은 대체 경로를 만들지 않고 재시도 상한과 수동 전환 조건을 명시한다.
