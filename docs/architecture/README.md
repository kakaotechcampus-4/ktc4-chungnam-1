# 아키텍처 기준

## 현재 방향

    Flutter 앱
    → 단말 로컬 저장
    → 단말 STT와 화자 처리 우선 검토 또는 동의 범위의 서버 임시 처리
    → 카드 및 리포트 처리
    → 보호자 확인
    → 프로필과 이야기 반영

별도 백엔드와 외부 LLM은 확정되지 않았다. 녹음과 이미지 원본은 동의한 기능에 필요한 경우 암호화하여 서버에서 임시 처리할 수 있으며 처리 완료 후 즉시 삭제하고 최대 24시간을 넘기지 않는다. 외부 업체 도입 전 직접 식별정보 제외, 로그, 삭제, 처리위탁과 국외 이전 조건을 확정한다.

## 역할 경계

| 영역 | 책임 |
| --- | --- |
| FE | Flutter 화면, 녹음 상태 화면, 사용자 권한, 앱 생명주기와 합의된 인터페이스 연동 |
| AI | 녹음 라이브러리, 음성 형식, STT 및 생성 모델의 선택, 입출력, 성능, 신뢰도와 실패 기준 |
| BE | 단말 데이터 구조와 로컬 DB, 모델 실행 연동, 처리 파이프라인, 데이터 경계와 선택적 서버 |
| QA | 평가 자료, 기준 정답, 평가 방식과 통과 기준 |

공통 데이터 계약은 FE, AI와 BE가 공동 관리한다. 하위 호환성을 깨는 변경은 ADR과 관련 README 갱신이 필요하다.
