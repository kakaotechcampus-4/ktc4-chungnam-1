# ADR-006: 온프레미스 GPU 서버에서 모델 추론

상태: accepted
담당: PM, BE, AI
결정일: 2026-09-14
관련 Issue: 미연결
대체: ADR-003(STT 병렬 검증), ADR-004

## 배경

회의에서 공유된 온디바이스 STT 벤치마크는 소형 모델과 주변 잡음이 없는 음성을 사용했다. 전사 품질은 나쁘지 않았으나 처리 속도가 느렸다. 잡음이 있는 환경에서는 품질이 더 낮아질 것으로 예상하며, 이는 아직 실측으로 확인한 결과가 아니다.

품질 확보를 위해 더 큰 모델을 사용하는 방향을 택했다. 대형 모델의 단말 실행은 처리 속도와 자원 제약이 커 GPU 서버에서 추론하기로 했다.

## 결정

- 모델 추론의 기본 실행 위치를 단말에서 온프레미스 GPU 서버로 전환한다.
- 초기에는 AI 담당자가 자택에 보유한 GPU를 사용한다.
- 상용 서비스와 유사한 운영 환경을 경험하기 위한 GPU 서버 임대는 검토 사항이며, 도입 여부와 업체는 미정이다.
- GPU 서버 구성·배포·운영과 모델 선택·실행 환경은 AI가 담당한다. 구체적인 구성과 모델은 검증 후 정한다.
- BE는 앱·서버 연동과 데이터 처리 경계를 담당하며, 모델 입출력과 오류 처리 기준은 AI와 공동 검토한다.

## 검토한 대안

- 온디바이스 유지: 측정된 처리 지연과 잡음 환경의 품질 우려로 기본안에서 제외한다.
- GPU 서버 임대: 초기에는 보유 GPU를 활용하고 필요할 때 재검토한다.

## 영향

- 앱과 서버 사이의 전송 시간, 연결 실패와 서버 가용성을 처리 흐름에 반영해야 한다.

## 검증

- 허가된 테스트 자료로 잡음 유무에 따른 전사 품질과 전송을 포함한 전체 처리 시간, GPU 메모리를 측정한다.

## 재검토 조건

- 보유 GPU의 품질, 처리 시간 또는 가용성이 요구 수준에 미달하는 경우
- GPU 서버 임대나 외부 AI 서비스를 도입하는 경우
