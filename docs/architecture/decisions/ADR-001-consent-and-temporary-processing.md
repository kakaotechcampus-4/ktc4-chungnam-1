# ADR-001: 동의 구조와 원본 자료의 임시 처리 경계

상태: accepted
담당: 주 PM 김영석, 부 PM 이예은
결정일: 2026-08-22
관련 Issue: 없음

2026-10-05 보완: 등록 사진과 분석용 임시 사본을 구분하는 PM 수정안을 [PR #92](https://github.com/kakaotechcampus-4/ktc4-chungnam-1/pull/92)에 반영했고 같은 날 병합했다. 2026-10-14 PM이 사진 보관과 AI 분석 동의를 가입 화면의 별도 선택 항목으로 받고 계정별 이력에 저장하는 방식으로 확정했다. 기존 운영 동의를 소급해서 바꾸거나 동의 및 삭제 구현이 완료됐다는 뜻은 아니다. 2026-11-09 기준 구현 상태는 아래 [현재 구현과 적용 조건](#현재-구현과-적용-조건)에 기록한다.

## 배경

새록은 보호자와 피보호자의 프로필, 음성, 전사 결과와 건강 관련 정보를 처리한다. 기존 로컬 전용 원칙과 서버 임시 처리안이 충돌해 동의 구조와 허용 범위를 먼저 정할 필요가 있다.

## 결정

- 가입 시 서비스 제공을 위한 개인정보 처리와 건강 관련 민감정보 처리 동의를 구분해 받는다. 해당 피보호자의 최초 정보 입력 전에 본인의 동의를 확인하며, 대리인이 동의하는 경우 동의와 적법한 대리 권한을 함께 확인한다. 매회 녹음 전 별도 확인 체크박스를 요구하지 않는 흐름과 실제 구현의 차이는 아래 절에 기록한다.
- 녹음과 사진은 해당 처리의 동의와 권한을 확인한 경우에만 암호화하여 서버로 전송한다. 보관 기준은 아래 구분을 따른다.
- 녹음 원본은 STT 처리 완료 후 즉시 삭제하며 서버 업로드 후 최대 24시간을 넘기지 않는다. 기존 제한을 유지한다.
- 사진 등록과 보관 동의, AI 이미지 분석 동의를 가입 화면에서 각각 선택 항목으로 받는다. 이미 유효하게 동의한 항목은 기능 사용 때 다시 묻지 않는다. 등록만으로 분석에 동의한 것으로 간주하지 않는다.
- 서비스 품질 개선용 가명정보 활용과 푸시 알림은 선택 동의로 둔다.
- 외부 STT와 LLM은 업체가 새록의 지시에 따라서만 처리하고 계약 이행에 필요한 경우에만 기능 필수 처리로 사용할 수 있다.
- 외부 업체 도입 전 처리위탁, 국외 이전, 보유기간과 자체 학습 여부를 확인하고 처리방침과 관련 문서를 갱신한다.

### 녹음 동의 확인 시점

상태: 2026-10-14 PM 문서 수정안. [API 명세의 계정 동의](../api-spec.md#1-계정)와 [PR #117](https://github.com/kakaotechcampus-4/ktc4-chungnam-1/pull/117)의 문서 보완 요청을 대조했다. 반복 체크박스를 제거하는 흐름을 정리하며, 동의 자체를 없애거나 실제 사용자 녹음 처리를 새로 승인하는 변경은 아니다.

| 시점 | 확인할 내용 | 현재 구현과 남은 작업 |
| --- | --- | --- |
| 최초 가입 | 보호자가 녹음과 음성 처리를 포함한 서비스 개인정보 처리 및 건강 관련 민감정보 처리에 각각 동의 | `POST /auth/consent`가 `serviceData`, `sensitiveData`와 동의 버전 및 시각을 저장한다. 피보호자 본인의 동의나 대리 권한을 증명하는 기록은 아니다. |
| 피보호자 최초 등록 전 | 해당 피보호자에게 처리 목적과 녹음 내용을 안내하고 본인의 동의를 확인. 대리인이 동의하는 경우 동의와 적법한 대리 권한을 함께 확인 | 확인 시점을 이 단계로 정리한다. 확인 방법, 기록할 항목과 FE 및 BE 연결은 후속 설계이며 현재 프로필 API에 구현돼 있지 않다. 보호자라는 관계만으로 대리 권한이 있다고 처리하지 않는다. |
| 매회 녹음 시작 | 앞서 확인한 동의 범위가 유지되는 상태에서 보호자가 녹음을 시작 | 같은 확인 체크박스를 매회 다시 받지 않는다. 마이크 사용 권한이나 녹음 버튼을 누른 사실만으로 피보호자의 동의와 대리 권한을 확인했다고 보지 않는다. |
| 녹음 서버 제출 | BE가 계정의 필수 동의와 회차 접근 권한을 확인 | 현재 음성 제출 코드는 계정 동의 두 항목을 검사한다. 피보호자별 동의와 대리 권한 확인까지 구현된 것으로 표시하지 않는다. |

- 동의를 철회했거나 동의 대상, 처리 목적 또는 범위가 달라진 경우에는 기존 가입 동의만으로 계속 처리하지 않는다. 재확인과 작업 차단 방법은 FE, BE 및 PM이 후속 계약에 반영한다.
- 녹음 도중 제3자가 참여하면 녹음을 중단하거나 해당 참여자의 동의를 확인한다는 기존 원칙을 유지한다.
- 피보호자별 확인과 철회 처리까지 검증하기 전에는 반복 체크박스 제거를 근거로 실제 사용자 자료의 수집 범위를 확대하지 않는다.
- 이번 문서 수정은 녹음과 전사문의 보관 기간, 서버 접수 후 기기 녹음의 삭제 시점, API 필드와 DB 구조를 바꾸지 않는다.

### 등록 사진과 분석용 임시 사본의 구분

상태: PR #92 문서 반영 및 병합 완료. 사진 보관과 AI 분석 동의의 가입 시 수집 및 계정별 저장은 2026-10-14 PM 확정, 동의 화면과 서버 연결 및 삭제 검증은 후속 작업(2026-11-09 기준 AI 분석 동의는 #257로 구현, 사진 보관 동의와 삭제 검증은 남음). 사진 보관 정책의 정본은 이 절이며 다른 문서는 이를 참조한다.

#### 사진 보관과 AI 분석 동의 시점과 저장 방식

- 최초 가입 화면에서 기존 필수 두 항목과 선택 두 항목에 더해, 사진 서버 보관과 AI 분석을 각각 별도의 선택 항목으로 받는다. 항목별 목적, 수집 항목, 보유 기간과 거부 영향을 안내한다. 사진 동의를 거부해도 가입과 사진 없는 기본 서비스는 이용할 수 있다.
- 기존 계정 동의 저장 구조인 `consent_records`에 사진 보관과 AI 분석 항목을 각각 추가한다. 동의, 거부와 철회는 버전 및 시각과 함께 이력으로 남기고 `current_consents`에서 최신 상태를 조회하도록 확장한다. 사진이나 프로필마다 동의를 다시 받지 않는다.
- 가입 때 동의했고 같은 목적과 범위가 유지되는 항목은 기능 사용 시 재요청하지 않는다. 미동의, 철회 또는 기록이 없는 계정이 사진 업로드나 AI 분석을 사용하려고 할 때만 필요한 항목을 안내하고 동의를 요청한다. 기존 계정에는 새 항목을 동의한 것으로 자동 적용하지 않는다.
- BE는 저장된 최신 동의를 검사한다. 보관 동의가 없으면 사진 업로드를, 분석 동의가 없으면 AI 분석을 허용하지 않는다. 보관만 동의한 사진은 분석하지 않고 저장할 수 있다. 분석 동의가 있다는 이유로 보관 동의를 대신하거나 사진을 업로드하지 않는다.
- 동의를 철회한 뒤 해당 기능을 다시 사용하려면 재동의를 받는다. 처리 목적, 항목이나 기간이 달라지는 경우에도 기존 동의로 자동 승인하지 않는다. 철회 시 등록 사진과 분석용 임시 사본을 처리하는 아래 기준은 유지한다.
- 휴대폰 사진 선택과 카메라 및 마이크 접근은 해당 기능을 사용할 때 처리하며, 서버 보관과 AI 분석 동의를 대신하지 않는다. 피보호자 본인의 동의 및 대리 권한은 최초 프로필 등록 전에 별도로 확인한다.
- 이번 결정은 동의를 받는 시점과 저장 방향을 정한 것이다. DB, migration과 API는 아직 변경하지 않았다(결정 당시 기준. 이후 구현은 아래 현재 구현 절). 필드명, 요청과 응답, 동의 변경 화면 및 철회 후 작업 중단과 삭제 실행은 FE 및 BE가 기존 계약에 맞춰 구현한다. 기존 구조에 반영하기 어려운 부분은 공유한다.

| 대상 | 목적과 보관 종료 기준 |
| --- | --- |
| 등록 사진 원본 | 앨범, 일대기와 면회 기록에 표시하기 위해 비공개 서버 저장소에 보관한다. 해당 사진 삭제, 사진 보관 동의 철회, 연결된 프로필 삭제 또는 회원탈퇴 시 지체 없이 삭제한다. 그 전이라도 보관 목적이 끝나 불필요해지면 삭제한다. |
| AI 분석용 임시 사진 | 별도 분석 동의를 확인한 작업에서만 만든다. 처리 완료 후 즉시 삭제하고 실패나 중단 시에도 해당 작업의 최초 임시 사본 생성부터 최대 24시간 이내 삭제한다. 재시도로 기한을 연장하지 않는다. |

- 이미지 분석 동의만 철회하면 분석을 중단하고 분석용 임시 사본을 삭제한다. 등록 사진은 별도로 동의받은 보관 목적이 유지되는 경우에만 보관한다.
- 사진 등록과 AI 분석은 전체 서비스 가입의 필수 조건으로 묶지 않는다. 사진 없이 직접 정보를 입력하는 경로를 유지한다.
- 법령상 별도 보존 의무가 확인된 경우에만 근거, 대상과 기간을 기록하고 분리 보관한다. 이 개정안은 사진의 영구 보관이나 분쟁 대응을 위한 추가 보관 기간을 승인하지 않는다.
- 24시간은 프로젝트의 임시 처리 제한이며 모든 사진에 적용되는 법정 보유기간이 아니다. 기존에 24시간 삭제를 조건으로 동의받은 자료가 있다면, 그 동의를 그대로 사용해 등록 사진의 보관 기간을 늘리지 않는다.
- 보호자의 업로드 동의만으로 사진 속 다른 사람의 정보 처리 근거가 확보됐다고 보지 않는다. 실제 사용자 자료를 받기 전에 정보주체의 동의 또는 적법한 대리 권한 등 처리 근거를 확인한다.
- 미확인 분석 결과의 보관 및 철회 시 처리 기준과 메타데이터의 구체적인 처리 범위는 이번 변경으로 확정하지 않는다. 사용자가 확인한 이야기 소재의 기존 보유 기준과 AI 후보를 사실로 자동 반영하지 않는 원칙은 유지한다. 2026-11-09 PM 결정으로 철회 시 저장된 AI 설명은 지운다([법률 문서](../../legal/README.md#사진-보관과-분석에-대한-pm-수정안)).

### 현재 구현과 적용 조건

PR #92는 사진 검증과 S3 저장, 조회 URL 생성 및 삭제 어댑터를 제공한다. 사진 API 연결과 삭제 대기열을 실행해 S3 원본을 지우는 처리는 아직 구현되지 않았다. DB 행 삭제나 삭제 대기열 등록만으로 원본 삭제가 완료됐다고 표시하지 않는다.

실제 사용자 사진을 받기 전에 동의 화면과 이력, 동의 철회 및 삭제 요청 경로, AI 임시 사본과 S3 원본의 실제 삭제를 검증한다. 기존 계약의 모든 프로필 사진 자동 분석과 새 동의 구분 사이의 차이는 FE, BE와 AI가 계약 및 구현에 반영해야 한다. 이번 문서 변경은 API 필드, DB와 분석 상태를 바꾸지 않는다.

## 검토한 대안

- 모든 처리를 단말에서만 수행
- 모든 데이터 활용을 하나의 필수 동의로 통합
- 서버와 외부 AI 처리 전체를 선택 동의로 구성

## 영향

- FE는 가입 시 필수 동의 두 항목과 피보호자 최초 등록 전 확인을 구분한다. 매회 녹음 전 같은 체크박스를 다시 요구하지 않는다. 사진 보관과 AI 분석은 가입 화면에 선택 항목으로 추가하고 미동의자의 기능 사용 시에만 필요한 동의를 요청한다.
- BE는 암호화, 등록 사진의 삭제 조건과 녹음 원본의 24시간 제한을 구현하고 삭제 결과를 확인한다. AI는 분석용 임시 사진의 삭제 기한을 지킨다. 임시 파일과 로그에도 같은 처리 경계를 적용한다.
- AI는 외부 요청에서 직접 식별정보를 제외하고 업체의 자체 학습 사용을 허용하지 않는다.
- PM은 외부 업체가 확정되면 처리방침과 국외 이전 고지를 갱신한다.

## 검증

- 가입 동의, 피보호자별 동의 및 대리 권한 확인을 구분하며, 매회 녹음 체크박스가 없어도 필요한 동의 확인을 건너뛰지 않는지 검증
- 피보호자별 확인 기록과 철회 처리는 아직 구현되지 않았으므로 계정 동의 검사 통과만으로 완료 처리하지 않음
- 사진 동의 두 항목을 거부해도 가입과 사진 없는 기본 기능 이용 가능
- 가입 시 동의한 사진 기능에 반복 요청 없음. 기록이 없는 기존 계정, 미동의 및 철회 계정은 해당 기능 사용 전 필요한 동의 요청
- 보관만 동의한 사진의 저장과 분석 차단, 분석 동의만으로 업로드하지 않는지 확인
- 동의 상태가 없는 녹음과 이미지 서버 업로드 차단
- STT 완료 후 녹음 원본 삭제와 AI 분석용 임시 사진의 완료 및 기한 삭제 확인
- 등록 사진의 삭제 요청, 보관 동의 철회, 프로필 삭제와 탈퇴 시 S3 원본까지 삭제 확인
- 분석 동의 거부 시 사진 보관과 분석을 분리하고, 분석 동의만 철회하면 임시 사본 삭제 및 분석 중단 확인
- 선택 동의 거부 데이터가 품질 개선 데이터셋에 포함되지 않는지 확인

## 재검토 조건

- 서버 처리 없이 기능을 제공할 수 있게 된 경우
- 외부 STT, LLM 또는 이미지 분석 업체를 도입하는 경우
- 원본 보유기간이나 처리 목적이 바뀌는 경우
