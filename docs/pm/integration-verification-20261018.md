## 2. 발견한 문제와 조사 결과

| 문제 | 확인한 내용 | 처리 방향 |
| --- | --- | --- |
| 대상 화자 불명확 | AI 요청에 화자 군집과 대상 프로필의 연결 정보가 없음. 군집 번호만으로 보호자와 피대화자를 구분할 수 없음 | AI가 확인 방법과 필요한 정보를 제안하고 BE, FE와 연결 |

| 후회와 미래 표현을 오류로 판정 | 기존 프롬프트가 지난날의 사실만 허용함. 초기 평가에서 문제로 지적한 희망 문장은 실제로 희망으로 정확히 요약됐음 | 해당 평가를 정정. 과거만 허용하는 조건을 수정 |
| 두 응답의 처리 실패 | 각 응답이 출력 한도 8,000토큰에 도달했고 JSON으로 읽지 못함. 당시 원문과 종료 사유를 남기지 않아 왜 길어졌는지는 미확인 | 모델과 한도 변경을 적용하고, 재발 시 종료 상태와 응답 형식을 확인할 수 있게 검사 |
| STT 오인식 | 파일 손상이나 화자 정렬 과정 이전인 음성 인식 단계에서 단어 오류 발생. 모델 및 음성 처리 조건 변경은 일부 개선과 악화를 함께 보임 | 최종 이야기, 질문과 리포트의 의미가 원래 대화와 맞는지를 우선 평가. 일괄 단어 치환은 하지 않음 |
| 리포트의 사건 순서 왜곡 | 모델이 발화 순서를 파악해도 자유로운 본문 작성에서 앞뒤 사건이나 마지막 장면을 바꾸는 사례 확인 | 원문에 없는 시간 관계를 만들지 않도록 생성 방식을 보완 |
| 마지막 선택 프로필 초기화 | 선택 정보가 메모리에만 남아 앱 재실행 시 첫 사용 가능 프로필로 돌아감 | 계정별 선택 프로필 유지. 후순위 작업 |

발언의 실제 진위를 이 시험으로 검증한 것은 아닙니다. 모델이 발언의 주체, 시점과 뜻을 보존했는지를 확인한 결과입니다.

## 3. 확정한 적용 기준

### 모델과 응답 한도

- 카드, 리포트와 이야기 후보 생성에 GPT-6 Luna를 사용합니다.
- 응답 출력 한도는 16,000토큰으로 높입니다. 입력 길이 제한을 16,000으로 정한 것이 아닙니다.
- 비교 시험의 추론 수준은 `low`입니다. 추론 수준을 새로 변경하기로 결정한 것은 아닙니다.
- 이 결정은 제품 설정에 아직 반영되지 않았습니다. 한도 확대가 과거 응답 오류의 원인을 해결했다는 뜻도 아닙니다.

### 이야기 추출

- 피대화자는 과거 경험, 현재 생각, 미래 계획과 후회를 말할 수 있습니다. 과거 경험만 허용하지 않습니다.
- 피대화자의 발언을 우선합니다. 발언을 따랐다는 이유만으로 객관적으로 사실임이 검증됐다고 표현하지 않습니다.
- 보호자의 의견과 사진 등은 보완과 정정에 참고합니다. 서로 다른 설명이 있으면 AI가 임의로 한쪽을 사실로 확정하지 않고 확인이 필요한 차이를 남깁니다. 구체적인 전달 방식은 담당자가 제안합니다.
- 보호자가 자기 경험을 말한 내용을 피대화자의 이야기로 옮기지 않습니다. 피대화자와 관련된 설명은 출처를 구분합니다.
- 미래 계획은 계획으로, 후회는 후회로 보존합니다. 이미 일어난 사건으로 바꾸지 않습니다.
- 이야기 후보는 기존 보호자 확인 흐름을 유지합니다. 후보 생성 자체가 승인이나 프로필 반영을 뜻하지 않습니다.
- 이 변경으로 사진 메타데이터를 다시 입력에 넣거나, 의료 판단과 안전 관련 기존 기준을 없애지 않습니다.

### STT와 후속 작업

- STT 단어 오류가 있어도 다음 AI가 문맥을 이해해 최종 결과의 의미를 보존하면, 그 오인식만으로 전체 기능 실패로 판정하지 않습니다.
- 인물, 시점, 부정 표현이나 중요한 경험이 최종 결과에서 바뀌면 수정 대상입니다. 이 기준은 STT 원문을 임의로 덮어쓰라는 뜻이 아닙니다.
- 대상 화자 연결은 구현으로 이어갑니다. 확인 화면과 저장 구조의 구체적인 형태는 아직 정하지 않았습니다.
- 선택 프로필 유지와 로컬 시제품의 실제 제품 적용 및 통합 재검증은 후속 작업입니다.

## 4. 해결안과 모델 비교 시험

### 해결안 시험

| 방법 | 결과와 제한 |
| --- | --- |
| 대상 화자의 발화만 전달 | 다른 화자의 질문 문맥이 사라져 짧은 답변의 의미를 잃음. 기본 방식으로 채택하지 않음 |
| 전체 대화와 대상 화자의 근거 번호 전달 | 화자와 근거 번호의 구조 검사가 가능함. 올바른 근거 번호만으로 내용 정확성을 보장하지 못함 |
| 별도 AI로 후보 의미 재검사 | 일부 오류를 찾았지만 정상 내용을 잘못 보류하는 사례도 있음. 자동 승인이나 삭제 기준으로 채택하지 않음 |
| 주제별 리포트와 근거 발화 연결 | 11회에서 정해진 인용과 형식 검사를 통과. 확인한 출력에서는 기존의 잘못된 마지막 장면 서술이 나타나지 않음. 제품 계약 변경은 미확정 |
| 선택 프로필 유지 시제품 | Flutter 테스트 14개 통과. 계정 구분, 삭제된 프로필과 오래된 비동기 응답 등을 검사. 저장소 대체 구현을 사용했고 실제 Android 종료 및 재실행 시험은 미실시 |
| 시험용 응답 및 경계 검사 | 15개 통과. 형식 검사만으로 의미 오류를 잡지 못하는 한계를 확인한 테스트도 포함. 모델 정확도 15건 통과라는 뜻이 아님 |

### Luna 비교

같은 입력, 프롬프트, 응답 스키마와 추론 수준 `low`로 모델을 비교했습니다. 모델의 응답 메타데이터도 확인했습니다. 개인 자료의 원문과 생성 내용은 공개하지 않습니다.

| 조건 | 호출 수 | JSON 처리 성공 | 출력 토큰 범위 |
| --- | --- | --- | --- |
| GPT-5.6 Luna, 한도 8,000 | 9 | 9 | 43~808 |
| GPT-6 Luna, 한도 8,000 | 9 | 9 | 36~628 |
| GPT-6 Luna, 한도 16,000 | 6 | 6 | 34~49 |

8,000 조건은 과거 실패한 합성 입력 2개를 각 3회 실행하고, 실제 대화의 대상 화자별 후보 2건과 리포트 1건을 더한 구성입니다. 16,000 조건은 같은 합성 입력 2개를 각 3회 실행했습니다. 24회가 서로 다른 대화 24개를 뜻하지 않습니다.

- 합성 입력 18회는 다른 사람의 경험을 대상자의 새 이야기로 만들지 않았습니다.
- 실제 대화 세 건은 5.6이 평균 9.55초, 6이 5.85초였습니다. 반복된 운영 성능 시험이나 전체 앱 처리 시간은 아닙니다.
- 6의 후보 한 건에서 예정된 사건과 이전 사건을 연결해 이미 일어난 것처럼 서술한 사례가 있었습니다. JSON 처리 성공을 내용 정확도 100%로 보고하지 않습니다.
- 과거 8,000토큰 소진은 이번에 두 모델 모두에서 재현되지 않았습니다. 한도 확대 필요성을 이 시험이 입증한 것은 아닙니다.
- 비교를 위해 시험용 프롬프트는 그대로 유지했습니다. 이번에 정한 이야기 추출 기준과 실제 서비스 프롬프트 전체를 검증한 결과는 아닙니다.

공식 Standard 단가의 100만 토큰 기준은 [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)가 입력 $0.20, 출력 $1.20이고, [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)는 입력 $0.10, 출력 $0.50입니다. 카테캠 ML API의 실제 차감 금액을 확인한 수치는 아닙니다.

각 기능 담당자는 자신의 정상 및 오류 경로를 먼저 확인합니다. 전체 검증을 특정 한 사람에게 넘기지 않습니다. 리더는 구현 담당자, 완료 예정일과 기다리는 작업을 해당 이슈에 기록합니다.
