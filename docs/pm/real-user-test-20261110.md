# 새록 실사용자 테스트 결과와 개선 항목

테스트일: 2026년 11월 10일

상태: 문서 PR 게시본, 기능 변경과 병합은 별도

확인 범위: PM의 현장 관찰, 해당 프로필의 운영 DB 기록, 생성 프롬프트와 데이터 전달 코드, PR #300~#313

첫 회차에서 리포트와 이야기 후보가 만들어졌고, 저장한 이야기를 다음 카드에서 다시 사용하는 흐름을 확인했다. 현장에서는 개인화가 약한 첫 추천과 대답하기 어려운 질문 방식이 문제로 드러났다. 두 번째 회차는 빈 전사로 분석에 실패했다.

이름, 계정, 생년월일, 시설명, 내부 식별자, 정확한 접속 시각과 실제 대화 원문은 싣지 않았다. 리포트와 이야기 본문도 전문을 옮기지 않고 기능 확인에 필요한 결과만 정리했다.

## 1. 테스트 조건

- 참여자 한 명의 프로필에서 회차 기록 두 개를 확인했다. 두 번째 회차에 실제 말소리가 녹음됐는지는 미확인이다. 그 회차의 재시도는 별도 사용자나 별도 회차로 세지 않았다.
- PM은 참여자가 중증 치매로 대화를 이어가기 어려웠으며, 이번에는 앱을 활용하기가 사실상 불가능한 수준이었다고 평가했다. 이는 현장 사용 소감이다.
- 새록의 기존 목표 대상은 경도인지장애 및 경도 치매 어르신과 보호자다. 이번 기록은 중증 사례에서 겪은 사용 어려움을 다룬다.
- 카드와 리포트의 저장된 모델명은 `gpt-6-luna`다. 카드 생성은 2판, 리포트 생성 기록은 `report-6+proposals-8`이다.
- 사진은 등록돼 있지 않았다. 이번 사례에는 사진 설명을 이용한 추천이 포함되지 않았다.
- 전사문 원문과 녹음을 이번 검토에서 재생하거나 대조하지 못했다. 새 AI 호출이나 재분석은 실행하지 않았다.

## 2. 현장 사용 소감

### 초기 입력과 추천의 연결이 약하게 느껴짐

초기에 입력한 내용과 관련된 주제가 적었다. 군고구마 같은 소재가 갑자기 등장했고, 현장에서 느낀 현재 계절과 다른 여름, 가을 소재도 함께 추천돼 개인에게 맞춘 카드라는 느낌이 약했다.

생성 기록에는 고향과 가족 입력이 포함돼 있다. 최종 첫 카드 12장은 일반 소재 10장과 비어 있는 직업, 취미를 묻는 카드 2장이다. 초기 정보를 직접 근거로 표시한 카드는 없었다. 고향과 가족 입력의 전달은 확인됐고, 최종 카드에서는 개인화 근거를 찾지 못했다.

조회 당시 직업과 취미는 비어 있었고, 고향과 가족에는 질문과 짧거나 불명확한 응답이 섞인 글이 저장돼 있었다. 개인 경험을 특정할 단서가 적었다. 다만 생성 당시 원문과 후보 제외 이유는 로그에 남기지 않으므로, 일반 소재가 많아진 원인을 입력 부족 하나로 확정하지 않는다.

### 현재 질문 방식으로 대화를 이어가기 어려움

참여자가 스스로 경험을 떠올려 길게 설명하기 어려웠다. 보호자가 주제나 단어를 먼저 던지면 그 표현을 따라 답하는 경우가 많았다. 리포트가 생성됐다는 결과와 실제 대화를 돕는 데 성공했다는 평가는 구분해야 한다.

PM은 전사에서 불분명하게 남은 표현이 실제 현장에서도 발음을 알아듣기 어려웠던 부분이라고 확인했다. 이번 중증 치매 참여자와 대화하며 겪은 어려움으로 기록하고, STT가 명확한 발화를 잘못 옮긴 결함으로 집계하지 않는다. 이는 원문과 녹음을 대조해 전사 정확도를 평가했다는 뜻은 아니다.

현재 카드 문안 지시는 열린 질문을 우선하며, 과거 경험을 설명하도록 묻는다. 인지 상태와 증상 메모는 카드 생성 입력에 보내지 않으므로 참여자의 상태에 맞춰 질문 난이도를 자동으로 조절하는 기능도 없다.

### 질문과 함께 짧은 단어 단서가 필요함

PM은 보호자가 바로 꺼내 쓸 수 있는 단어 추천도 필요하다고 제안했다. 현재 카드는 설명, 첫 질문과 꼬리 질문 세 개를 제공하며, 별도 단어 목록은 없다.

후속 검토에서는 질문 문장과 함께 짧은 단어 단서를 주는 방식을 다룬다. 보호자가 제시한 말을 되풀이한 응답을 실제 생애 경험으로 받아 적는지도 함께 점검해야 한다. 단어 추천 기능의 추가 여부와 화면 구성은 아직 확정하지 않았다.

### 화면 사용 불편은 별도 PR로 수정 중

녹음 상태를 알아보기 어렵고, 질문을 넘기는 조작이 예상과 다른 문제가 있었다. 현장 지적 뒤 진행한 코드와 화면 점검에서 찾은 항목까지 PR #300~#313에 나누어 올렸다. 모든 항목이 이번 참여자에게 실제 발생한 문제라는 뜻은 아니다.

## 3. 서버에 남은 처리 결과

| 확인 항목 | 첫 번째 회차 | 두 번째 회차 |
| --- | --- | --- |
| 카드 생성 | 12장 완료 | 12장 완료 |
| 카드 생성 함수 기록 시간 | 36.7초 | 35.3초 |
| 카드 구성 | 일반 소재 10장, 빈 초기 정보 질문 2장 | 일반 소재 10장, 승인한 이야기 활용 2장 |
| 녹음 제출 후 분석 | 약 23초 뒤 완료 | 최초 제출과 재제출 모두 `EMPTY_TRANSCRIPT` |
| 리포트 | 제목과 본문 생성, 본문 210자와 세 문단 | 생성되지 않음 |
| 이야기 후보 | 2개 생성 후 2개 모두 일대기에 저장 | 없음 |
| 주제 조정 제안 | 없음 | 없음 |
| 다음 추천 반영 | 저장한 이야기 2개를 두 번째 묶음의 카드 2장이 근거 ID로 참조 | 후속 분석 결과 없음 |

카드 생성 시간은 생성 함수가 기록한 값이다. 사용자가 버튼을 누른 뒤 기다린 전체 시간과 같다고 보지 않는다.

첫 리포트는 과거 놀이 경험을 중심으로 두 화제를 정리하고 대화 마무리를 덧붙였다. 보호자 소감에는 소통이 어려웠다는 내용이 남아 있다. 다음 카드 두 장이 저장된 이야기를 참조한 것은 DB의 근거 연결로 확인했다. 해당 카드가 실제 다음 대화에서 사용됐거나 도움이 됐는지는 별도 확인이 필요하다.

| 항목 | 확인된 내용 | 후속 확인 |
| --- | --- | --- |
| 첫 카드의 개인화 부족 | 초기 정보 두 칸이 입력에 포함됐으나 최종 카드에 초기 정보 근거를 단 카드가 없음 | 불명확한 입력을 다루는 방법과 개인화 후보를 최종 묶음에 남기는 기준 점검 |

| 제시한 단어와 실제 경험의 구분 | PM은 주어진 단어를 따라 답한 경우가 많았다고 관찰함. AI는 경험 형태의 이야기 후보를 만듦 | 보호자의 질문, 단순 반복 응답, 참여자의 경험 진술을 구분하는 사례로 검토. 원문 부재로 이번 후보의 사실 오류를 확정하지 않음 |
| AI 분류와 최종 분류의 차이 | 후보 두 개는 취미, 저장된 이야기 두 개는 고향으로 분류됨 | 사용자가 분류를 바꾼 경우와 전송 문제를 구분. 현재 코드는 사용자가 보낸 분류가 없으면 AI 분류를 쓰므로 차이만으로 버그라고 단정하지 않음 |
| 등록한 인지 상태 확인 | 프로필에 선택한 상태와 PM의 현장 설명이 다름 | 등록값 확인. 인지 상태는 카드 생성 입력에서 빠지므로, 이 차이를 이번 추천 결과의 원인으로 설명하지 않음 |
| 두 번째 회차의 분석 실패 | 두 요청 모두 사용할 전사 내용이 없어 실패. 녹음 파일 크기는 0바이트가 아니었음 | 기기 녹음이 남아 있다면 실제 말소리와 전사 처리 결과 확인. 파일 크기만으로 말소리 녹음 성공을 판단하지 않음 |
| 원문 대조 불가 | 첫 회차 전사문은 리포트 완료 시 삭제됐고, 서버 녹음도 삭제 처리됨. 두 번째 회차에는 저장된 전사문이 없음 | 현재 자료로 리포트 정확도와 누락률을 산출하지 않음. 추가 시험에서는 필요한 비교 자료와 보관 범위를 사전에 정함 |

PR #300과 #302의 녹음 문제는 확인과 수정 대상이지만, 이번 두 번째 회차의 빈 전사를 일으킨 원인으로 확인된 것은 아니다. 현장에서 알아듣기 어려웠던 발화와 두 번째 회차의 `EMPTY_TRANSCRIPT` 실패는 구분한다. 후자의 원인은 아직 확인되지 않았다.
