# 보호 기능별 코드 근거

이 문서는 [최종 보고서](README.md)에 소개한 보호 기능 76개가 어느 코드에 있는지 설명한다. 각 표는 막으려는 문제, 구현한 보호, 확인 조건 순서다. 마지막 열의 링크를 누르면 검토한 버전의 코드를 볼 수 있다.

BE는 앱 요청을 처리하는 서버, DB는 계정과 자료를 저장하는 데이터베이스, STT는 음성을 글로 바꾸는 기능이다. 기술 용어와 정확한 설정값은 코드 확인에 필요한 곳에 함께 적었다.

코드를 확인한 버전은 `951307b9dfc8862f38673fb57e469a175807f110`이다. 이후 추가된 앱 화면 변경, 카드 3판과 AI 재시도는 [이후 변경](README.md#확인한-코드-버전과-이후-변경)에 따로 정리했다. 이 추가 변경 전체를 다시 보안 검토한 것은 아니다. 운영진 AWS와 토큰, 기존 Tailscale은 팀 수정 범위에서 제외한다.

사진 보관과 AI 분석 동의는 구분해야 한다. 현재 처리방침은 사진 보관을 필수 서비스 동의에 포함하고 AI 분석을 선택으로 설명한다. 오래된 README/계약에는 별도 사진 보관 동의를 아직 구현하지 않았다는 설명이 남아 있다. **사진 AI 철회 구현은 확인됐으며, 보관 동의의 서로 다른 문서는 정리가 필요하다.**

**파일별 삭제 확인 방식:** 이전 버전을 보관하는 사진 저장소는 일반 삭제 프로그램이 처리하지 않는다. 면회 음성의 빠른 삭제는 삭제 요청 성공 후 상태를 기록한다. 짧은 전사는 삭제 요청 성공 뒤에도 대기 목록을 유지하고, 별도 프로그램이 파일이 없다는 응답(HEAD 404)까지 확인한다. 두 음성 처리 경로의 완료 확인 수준은 다르다. [짧은 전사 삭제](https://github.com/kakaotechcampus-4/ktc4-chungnam-1/blob/951307b9dfc8862f38673fb57e469a175807f110/backend/app/services/speech_transcription.py#L110).

과거 DB 백업을 운영에 복원하면 그 이후의 탈퇴, 동의 철회, 토큰 폐기를 재적용해야 한다. 자동 절차는 확인되지 않았다. 다만 [복구 문서](https://github.com/kakaotechcampus-4/ktc4-chungnam-1/blob/951307b9dfc8862f38673fb57e469a175807f110/backend/docs/release-safety.md#L169)는 자동 복원을 금지하고 사전 승인을 요구한다. 실제 탈퇴 자료가 되살아난 사건을 확인했다는 뜻은 아니다.
