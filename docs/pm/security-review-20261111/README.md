작성일: 2026-11-11. 게시 전 PR 상태 확인은 02:34 KST 기준이며 모든 시각은 한국 시간이다.

## 1. 결론

새록에는 로그인 검증, 계정별 자료 접근 제한, 동의 철회 반영, 파일 업로드 제한, AI 도구 권한 제한, 출력 검사, 개인정보 로그 축소, 단말 자료 분리와 배포 전 검사가 구현돼 있다. 이번에 정리한 보호 조치는 76개이며, 관련 PR은 60건이다. **두 숫자 모두 발견하거나 해결한 취약점 수가 아니다.**

기존 점검의 확정 문제 4건 중 인증 전 대용량 본문 문제는 수정이 병합됐고 Caddy 제한 적용 기록도 있다. 나머지 **STT 파일 처리 3건은 원인 코드가 남아 있다.** S3 자동 삭제는 구현된 실행기를 실제 운영에 예약하는 작업 등이 PM 보류 상태다.

개발 중 후속 확인은 해당 기능을 바꾸거나 배포할 때 함께 처리한다. 운영진이 관리하는 AWS와 토큰, 기존 Tailscale 연결은 팀의 미해결 보안 이슈에서 제외한다. 제품 코드와 날짜가 있는 실행 기록을 구분한 보고서이며 보안 인증이나 무결점 판정은 아니다.

## 5. 프롬프트 인젝션과 AI 안전성

사진 설명, 이야기나 전사문에 “앞의 지시를 무시하라” 같은 문장을 넣어 AI의 동작을 바꾸려는 입력에 대해 다음 보호가 있다.

| 단계 | 이미 구현한 제한 |
|---|---|
| 입력 | 시스템 지시와 사용자 자료를 구분하고 자료 안의 명령을 따르지 않도록 안내 |
| 도구 | 카드 조사 도구 6개를 전달받은 한 프로필의 읽기에 한정. 임의 계정 선택, DB 쓰기, 셸 실행 도구 없음 |
| 출력 | 근거 ID, 카드 구성, JSON 형식, 일부 의료 표현과 질문 문구 검사 |
| 사실 확정 | 이야기 후보를 확인 대기로 두고 보호자가 승인한 뒤 저장 |

코드 근거는 [AI 보호 조치](controls.md#5-ai-권한과-출력-보호)에 있다. 입력 지시, 도구 권한과 결과 검사를 함께 적용한다. 모든 잘못된 해석을 막는다는 보장은 없다.

[PR #316](https://github.com/kakaotechcampus-4/ktc4-chungnam-1/pull/316)은 @decmoon05가 작성하고 **11월 11일 02:08에 병합**한 시험 보고서다.

- 시험 코드: develop `a855c87e`, 카드 2판, report-6, proposals-9.
- 모델: `gpt-6-luna`, 합성 입력.
- 범위: 이야기 및 세부 정보 기반 카드 7회, 사진 설명 기반 카드 7회, 리포트 7회, 변경 제안 7회. 총 28회.
- 보고된 결과: 시험 출력에서 삽입한 표식, 외부 링크, 시스템 지시문, 지어낸 진단이나 이야기가 나오지 않았다.
- 한계: 사진 속 글자를 직접 읽는 분석, 앱 입력부터 저장까지의 전체 흐름, 대량 반복과 후속 프롬프트 변경은 시험 범위 밖이다. 재실행 스크립트도 저장소에 포함되지 않았다.

이번 보고서는 [병합된 시험 문서](https://github.com/kakaotechcampus-4/ktc4-chungnam-1/blob/6836ac8052067d50db1e24e39ab65cf21d5bc15e/docs/qa/prompt-injection-20261110.md)를 대조한 것이다. 모델을 다시 호출하거나 결과를 독립 재현하지 않았다. 인젝션 저항성과 가족 관계 및 사진 설명의 사실 정확성은 별도로 평가한다.

STT의 첫 WAV 검사는 이미 스레드로 넘기며 정상 임시 파일 정리와 시작 전 기한 검사도 있다. 남은 문제는 후속 동기 파싱, 디코더 차이, 강제 종료와 실행 중 취소 경계다. **Tailscale 연결 방식을 다시 바꾸는 작업과는 별개다.**

확정된 새 담당 배정이나 개발 중단 조건을 추가하지 않았다. 항목별 완료 조건과 보류 기준은 [후속 작업표](follow-up.md)에 정리했다.

| GitHub 배포 승인 | 기존 PM 승인 절차와 main/develop 배포 범위 유지. 이번 보고서로 승인 정책 변경 없음 |
