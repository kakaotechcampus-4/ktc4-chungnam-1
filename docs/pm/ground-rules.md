# 팀 그라운드룰

충남대 1팀이 2단계 시작 때(2026-08-17 작성, 08-18 팀 공유) 정한 협업 기본 규칙이다. 문안은 공유 당시 그대로 옮겼다. 지난 마감 일정과 8/18 회의 안건 목록만 뺐다.

개발 규칙(브랜치, 커밋 메시지, PR과 리뷰, 코드 검사)은 이 문서가 아니라 [협업 규칙](../../CONTRIBUTING.md)을 따른다. 저장소 작업에서 AI 도구가 지킬 금지 규칙은 [AGENTS.md](../../AGENTS.md)와 `CLAUDE.md`에 있다.

## 1. 채널
- 노션: 확정된 산출물과 결정
- 디스코드: 진행 상황, 질문, 다가올 일정
- `알림` 채널은 알림 켜두기
- DM 지양. 결정은 노션에 한 줄로 남기기 (메이커)

## 2. 공지 확인
- `알림`, `공지` 글은 읽고 체크 반응 남기기. 표시 없으면 안 읽은 것으로 본다
- 플래너는 체크 안 된 사람만 추가 멘션
- 카테캠 공식 공지는 플래너가 `알림` 채널로 옮겨 올린다

## 3. 작업 공유
- 착수: "OO 잡습니다"
- 완료: "OO 올렸습니다" + 링크
- 막힘: 바로 공유. 혼자 붙잡지 않기
- 과제 항목마다 담당자 1명. 같은 칸 동시 편집 금지
- 큰 재작성은 페이지 복제해서 하고 다 되면 교체
- AI에게 노션 작업 시킬 때 페이지와 섹션 범위를 먼저 지정

## 4. AI
- 적극적으로 쓴다. AI 티는 신경 쓰지 않는다
- 무슨 툴로 뭘 도움받았는지 한 줄 기록
- 자기 담당은 아래를 막힘 없이 설명할 수 있어야 한다
  - AI: 모델 이름과 버전 / 왜 그 모델인지 / 입력, 출력, 컨텍스트에 들어가는 것 / 툴 호출 여부와 시점 / 틀렸을 때 처리
  - 백엔드: 무슨 데이터를 받아 무엇을 돌려주는지 / 저장 위치와 형태 / 실패 시 응답 / 전체 흐름에서의 위치
  - 프론트: 화면 상태 / 데이터 출처 / 로딩, 에러, 빈 결과 화면
- 내가 설명 못 하는 코드가 내 PR에 있으면 아직 안 끝난 것
- 발표와 Q&A 중 AI 실시간 참조 금지 (카테캠 규정)

## 5. 회의
- 불참은 미리 공유. 사후 통보 없음
- 회의록에 결정, 담당자, 기한 세 가지 필수 (메이커)
- 4주차부터 LXP 강의실 접속과 웹캠 필수

## 6. 피드백
- 반대는 사람이 아니라 기준에 대고 한다
- 후보 검토할 때 공격 담당 1명 지정
- 실수 비난 금지, 모르면 바로 질문

## 7. 부하
- 대신 해주지 말고 방법을 알려준다
- 주 PM이 막히면 부 PM이 결정

## 8. 마감
- 플래너가 1주 전, 3일 전, 하루 전 리마인드
- 제출은 대표자 1명
