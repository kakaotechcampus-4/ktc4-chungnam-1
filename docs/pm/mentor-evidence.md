# 멘토 심사 항목별 근거 위치

관리: 김영석 | 갱신: 2026-11-04

심사 항목마다 구현이 어디 있고 어떤 실행 기록으로 확인했는지 모은다. 상태는 세 가지로 나눈다.

- develop: develop에 병합됨
- PR: PR로 올라가 리뷰 중이며 아직 병합되지 않음
- 미실행: 구현은 있으나 실제 환경에서 실행한 기록이 아직 없음

실행 기록이 없는 항목을 된 것으로 쓰지 않는다. PR이 병합되거나 실행 기록이 생기면 이 문서를 갱신한다.
