# 멘토 심사 항목별 근거 위치

관리: 김영석 | 갱신: 2026-11-09

심사 항목마다 구현이 어디 있고 어떤 실행 기록으로 확인했는지 모은다. 상태는 네 가지로 나눈다.

- develop: develop에 병합됨
- 운영 반영: 운영 서버 배포본에 들어감. 앱 화면은 Play 프로덕션 첫 게시 검토 중(11/8)이라 develop으로 빌드한 APK에서만 볼 수 있음
- PR: PR로 올라가 리뷰 중이며 아직 병합되지 않음
- 미실행: 구현은 있으나 실제 환경에서 실행한 기록이 아직 없음

실행 기록이 없는 항목을 된 것으로 쓰지 않는다. 11/4 로컬 AI 실측(3, 5, 6, 7번)은 합성 대화로 한 것이다. 처음 짧은 대본(회차당 7~12줄)으로 낸 결론은 30분 분량 대화로 다시 돌려 고쳤다(6번). 표본이 작아 경향으로만 쓴다. 11/5에 11/3 이후 올린 PR을 develop에 병합했다. 11/9에 develop `d9643466`까지 병합한 PR 가운데 심사 항목의 근거로 쓸 것, 운영 배포 기록(GitHub Actions Deploy workflow)과 11/8 운영 안정성 시험을 더했다. 11/3~11/9 병합 PR을 모두 옮긴 것은 아니다. PR이 병합되거나 실행 기록이 생기면 이 문서를 갱신한다.
