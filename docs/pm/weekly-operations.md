# 주간 회의와 보고서 운영

## 카테캠 필수 기준

- 리뷰 미팅: 주 1시간, 팀 전원 LXP 접속
- 협업 미팅: 주 4시간, 관련 작업자 최소 2명 LXP 접속
- 온라인 미팅: 웹캠 필수
- 위클리 보고서: 매주 일요일 22시까지 제출
- 보고서 내용: 팀 활동, PR 링크, 진행 상황, 다음 주 계획

## 팀 운영안

1. 일요일 20시까지 각자 다음 주 가능 시간 공유
2. PM이 전원 가능한 리뷰 미팅 1시간 확정
3. 관련 작업자끼리 협업 미팅 4시간 구성
4. 메이커가 팀 내용을 취합해 일요일 22시까지 보고서 제출

시간 공유 방식은 카테캠 제공 기능이 아니며, 노션이나 디스코드 등 팀 도구를 사용한다.

## 작업 추적

구현 담당자가 세부 작업을 작성하고 PM은 범위, 완료 조건과 우선순위를 검토한다. 이슈 작성과 완료 처리 방법은 [협업 규칙](../../CONTRIBUTING.md)을 따른다.

- 미완료 작업은 기존 이슈의 진행 상태를 갱신하며 이어간다. 주차가 바뀌었다는 이유로 같은 작업의 이슈를 다시 만들지 않는다.
- 설계, 계약, 실험 조건과 실행 방법은 [문서 안내](../README.md)의 기존 정본 한 곳에 남기고 이슈와 보고서에서 링크한다. 미완료 작업 자체를 문서로만 옮기지 않는다.

## 주간 보고 작성 기준

첫 줄에는 현재 사용자가 앱에서 실제로 할 수 있는 흐름과 아직 연결되지 않은 부분을 적는다. 실제 서버, AI와 저장에 연결된 구간과 목 데이터 또는 타이머로 움직이는 구간을 구분한다.

| 구분 | 기록할 내용 |
| --- | --- |
| 완료 | 이번 주 추가되거나 확인된 동작, 관련 이슈와 PR, 실행 근거. 코드 병합만 된 상태와 실제 동작 확인을 구분한다. |
| 진행 및 이월 | 기존 이슈 링크, 남은 작업과 다음 확인 계획 |
| 막힘 | 기존 이슈 또는 PR 링크, 막힌 원인, 필요한 선행 작업이나 답변과 확인할 담당 |
| 다음 주 | 이어갈 작업의 이슈 링크와 인계할 산출물 |

위 요약에 카테캠 필수 항목인 팀 활동, PR 링크, 진행 상황과 다음 주 계획을 포함한다. 제출 담당과 마감은 위 운영안을 유지한다.
