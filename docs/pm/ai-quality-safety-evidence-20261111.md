추가 확인: 2026-11-11 01:24 KST, #317 짧은 전사 오류 대응과 #307 AI 처리 실패 안내

새록의 카드 추천, 사진 설명, 음성 전사, 리포트와 이야기 후보를 점검한 자료를 모았다. 시험 결과, 발견한 문제, 수정 내용과 재검증 기록을 연결한다. 멘토 심사의 **⑥ AI 품질 점검과 개선 노력(5점)**, **⑦ AI 안전성과 예외 대응(10점)**을 확인할 때 사용할 수 있다.

AI 처리 실패를 사용자에게 알리고 다시 진행하도록 돕는 작업도 포함한다. 일반적인 로그인, 녹음 권한과 화면 배치 개선은 이 자료 모음에서 제외한다.

각 시험의 수치는 당시 모델과 코드의 결과다. 실제 모델 시험, 합성 응답을 쓰는 자동 테스트, 실사용자 관찰을 구분했다. 이번에는 기존 자료와 PR의 실행 기록을 대조했으며, 모델 호출이나 전체 테스트 재실행, 운영 서버 시험은 하지 않았다.

- 흐리거나 작은 옛 사진에서 인물별 특징과 행동을 구분하는지 확인한다. 애매한 세부를 생략한 결과는 맞게 알아본 것으로 세지 않는다.

- 경도인지장애와 경도 치매라는 목표 대상에서 질문이 답하기 쉬운지 검토한다. 작성된 사람 검수표와 실사용자 관찰을 활용한다.
- 프롬프트나 모델을 바꾼 뒤 기존 안전 사례를 다시 실행한다. 사진 속 지시문, 장시간 입력과 반복 생성은 기존 인젝션 시험을 확장할 대상이다.

## 6. 자료를 인용할 때 확인할 점

- **형식 성공과 내용 정확도를 구분한다.** 306건의 JSON 형식 통과, 사진 86건 완료, AI 단위 테스트 통과는 각각 다른 검사다.
- **옛 정책은 현재 기준과 대조한다.** 11/3 문서의 화자 라벨 부족 시 생성 차단은 이후 변경됐다. 현재 동작은 [화자 처리 기준](../../backend/docs/speaker-fact-boundary.md)을 따른다.
- **발견 당시 상태와 수정 후 상태를 구분한다.** 11/8 무음 오인식은 11/9 STT 비교와 함께 읽고, 긴 면회 후보 수 문제는 #295 이후 결과와 함께 읽는다.
- **모델 호출 횟수는 독립 표본 수가 아니다.** 같은 입력의 SDK 호환 확인, 한 카드 묶음의 여러 생성 단계, 동일 사진 반복 분석을 별도 사용자 수로 계산하지 않는다.
- **사람의 판단과 AI 판정을 구분한다.** VAD 비교의 표본 추정은 AI 판정이고, 카드 사람 검수표는 아직 채점 결과가 없다.
- **서버와 사용자의 원본을 구분한다.** 분석 복구, 전사 보관과 S3 삭제 처리는 각각의 자료 위치와 기한을 따른다. 기기 녹음을 서버 녹음과 같은 기준으로 삭제한다고 설명하지 않는다.
