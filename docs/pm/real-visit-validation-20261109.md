## 남은 점

- 실행마다 후보를 나누는 정도가 조금씩 다르다. 의견이나 지인 소식이 가끔 후보로 들어오고, 누구 이야기인지 잘못 붙는 경우가 있어 보호자 검토가 필요하다.
- 이 확인에 쓴 전사는 기본 STT 서버와 같은 예전 설정(VAD 끔)으로 만든 것이다. 녹음 앞부분 약 1분이 같은 소리의 되풀이로 사라졌고, 끝부분에 지어낸 반복 문장이 있었다. 기본 STT 서버에도 #276(VAD) 반영이 필요하다.
- 녹음과 전사는 확인 뒤 학교 GPU 서버와 운영 서버의 임시 위치에서 지웠다. 운영 서버와 주고받은 전사와 결과는 그때만 쓰는 키로 암호화했다.
