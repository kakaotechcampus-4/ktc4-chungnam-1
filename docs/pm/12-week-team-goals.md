# 12주 팀 목표

각 팀원이 자신의 담당, 결정 이유, 실패와 검증 결과를 GitHub 기록과 결과물로 설명할 수 있는 프로젝트를 완성한다.

| 목표 | 남길 결과 |
| --- | --- |
| GitHub 협업 | 목적과 완료 조건이 있는 이슈, 기능별 PR, 담당자 리뷰, 피드백과 충돌 해결 기록 |
| 공통 AI 개발 지침 | 루트와 역할별 AGENTS.md 및 CLAUDE.md, 확정/미정 구분, AI 생성물의 리뷰와 검증 |
| 제품 통합 | 프로필 → 카드 → 면회 → 보호자 평가와 음성 처리 → 리포트 → 승인 → 다음 추천과 스토리북 |
| 가설 검증 | 맞춤 카드 선택, 기록 활용, STT와 화자 처리, 관찰값 일치도, 재사용 측정 |
| 실패 대응 | 카드 수정과 제외, 저신뢰도 결과 중단, 수동 입력, 승인과 되돌리기 |
| 개인정보 | 목적과 데이터 흐름, 전송 최소화와 마스킹, 동의/보관/삭제, 외부 처리 경로 확인 |
| 역할별 설명 | 해결한 문제, 담당 작업, 선택 이유, 실패와 개선, 검증 방법, 전체 제품과의 연결 |

기능별 수치와 검증 기준은 [테크스펙](../tech-spec.md), 현재 제품 범위와 역할은 [PM 기준](README.md), 진행 상태는 GitHub 이슈와 PR에서 관리한다.

실제 사용자 자료와 마스킹한 실제 자료는 저장소에 올리지 않는다. 개인 자료의 보관과 제품 검증을 구분하고 [법률 문서](../legal/README.md)의 동의 및 처리 조건을 따른다.
