# 공개용 검사 근거

[보고서](../README.md)의 근거 자료다. 모두 합성 대화와 시험용 프로필을 사용했다. 실제 가족 자료, 실제 계정의 프로필 이름, 운영 식별자, 인증정보와 녹음 파일은 포함하지 않았다.

## 자료

- [검사 목록 62개](checklist.json): 완료 50개, 일부 확인 9개, 실기기 미실행 3개. 숫자는 기능별 확인 범위이며 출시 승인 점수가 아니다.
- [자동 검사 결과](automatic-test-results.md): 종료 출력, 실패와 재검사, 발췌 전 원본 SHA256.
- [운영 연결 화면 문구](synthetic-ui.json): 두 리포트, 이야기 수정 승인, 다음 카드 반영, 정정과 삭제 후 재생성. 합성 수선집 이름과 내용을 사용했다.
- [실제 마이크 상태](microphone-state.json): 백그라운드와 화면 꺼짐 중 프레임 증가. 해당 주변 음성은 서버에 제출하지 않았다.
- [운영 리포트의 합성 면회 사진](report-photo.png): 카메라 결과만 앱 그림으로 대체하고 실제 업로드와 리포트 표시를 확인한 화면. 좌측 상단 검은 막대는 시험 기기의 보조 도구다.

## 검사 종료 상태

2026-11-11 14:07 KST 원래 APK로 복원했다. 설치 파일 SHA256은 `294d170c30fb2f5f1a3e6ba2aeb34f1ef25cf0f27c177fb82bd7cadaf73d22da`다. 로그인과 선택 프로필 유지, 마이크와 알림 권한 복원, 녹음 서비스 미실행을 확인했다. 충전 중 화면 켜짐 설정을 유지했다.

삭제 기능은 합성 프로필과 합성 이야기에서만 실행했다. 삭제한 시험 자료는 앱에서 복구할 수 없으며 로컬 검사 기록은 보존했다. 기존 사용자 프로필 두 개는 유지했다.

## 해석 범위

- 실제 서버 연결에는 합성 WAV를 제출했다. 실제 두 사람의 발음과 화자 분리 정확도를 검증한 결과가 아니다.
- S22 자동 여정 3개는 실제 화면을 조작하지만 서버, 마이크와 카메라 응답은 시험 대역이다.
- 중단된 S22 일괄 자동 실행의 종료 표시는 `+147 -5`다. 이후 해당 항목 재검사를 통과했지만 최초 실행 전체를 통과로 바꾸지 않았다.
- 최신 코드의 Flutter 전체 실행에서 PC 내부 테스트 실행기 연결이 끊겨 7개 파일을 시작하지 못했다. 최초 결과와 해당 파일의 후속 결과를 따로 기록한다.
- 실제 계정 탈퇴, 운영 동의 철회, Play 설치, TalkBack 음성, 실제 녹음 청취와 운영 DB 중복 작업 수 등은 보고서의 제한 항목에 남겼다.
