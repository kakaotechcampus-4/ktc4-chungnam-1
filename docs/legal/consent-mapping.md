# 동의 문구와 기능 대응표

상태: 운영 중

이 문서는 `consent-draft.md`의 문구를 변경하지 않고, 각 문구가 적용되는 기능과 대응하는 법적 쟁점을 설명한다. `대응됨`은 문구와 기능이 연결됐다는 뜻이며, 실제 구현과 운영까지 자동으로 적법해졌다는 뜻은 아니다.

## 대응 수준

- 대응됨: 동의 문구에 목적, 항목, 기간과 거부 영향을 반영함
- 부분 대응: 동의 문구가 있으나 권한 확인, 삭제 증명이나 제3자 동의가 추가로 필요함
- 미대응: 현재 동의문에 해당 기능이나 데이터 처리가 포함되지 않음

## 문구별 기능과 법적 쟁점

| 동의 문구 | 연결 기능 | 적용 시점 | 대응 법적 쟁점 | 대응 수준 | 구현과 운영에서 남은 조건 |
| --- | --- | --- | --- | --- | --- |
| 서비스 제공을 위한 개인정보 처리 동의 | 회원가입, 피보호자 프로필, 카드, 녹음, STT, 화자 처리와 리포트 | 최초 가입과 피보호자 등록 전 | 보호자와 피보호자의 일반 개인정보 처리, 음성 수집, 서버 임시 저장, 목적에 필요한 최소 수집 | 부분 대응 | 실제 로그인 항목을 확정하고 녹음 원본, 임시 파일과 로그를 최대 24시간 안에 삭제해야 함 |
| 건강 관련 민감정보 처리 동의 | 인지 상태, 대화 주의사항, 발화 분석 결과, 금기 질문 차단 | 민감정보 최초 입력 전 | 건강 관련 민감정보를 일반 개인정보와 구분하여 별도 동의 | 대응됨 | 별도 체크박스로 받아야 하며 암호화, 접근 통제와 삭제 절차가 필요함 |
| 피보호자에게 안내하고 동의를 확인했다는 확인 | 녹음 시작, 피보호자 정보 처리 | 녹음 시작 전 | 앱 사용자가 아닌 피보호자의 의사 확인 | 부분 대응 | 자녀라는 이유만으로 대리권이 생기지 않으며 동의자와 권한 근거를 기록해야 함 |
| 제3자 참여 시 녹음 중단 또는 별도 동의 | 다인 면회실 녹음 | 제3자 참여 감지 또는 확인 시 | 보호자가 참여하지 않은 타인 간 대화 녹음, 제3자 음성 수집 | 부분 대응 | 녹음 일시정지, 구간 삭제 또는 제3자 동의 절차가 실제 화면과 파이프라인에 필요함 |
| 이미지 분석 기능 이용 시 필수 동의 | 프로필 이미지 등록, VLM 분석, 이미지 기반 소재 추천 | 이미지 분석 실행 전 | 이미지 개인정보의 처리 목적, 분석 항목, 원본 보유기간 고지 | 부분 대응 | 로컬 처리인지 외부 처리인지 확정하고 얼굴 식별과 건강정보 추론을 하지 않도록 제한해야 함 |
| 외부 AI 처리 안내 | 외부 STT, 화자 처리, 외부 LLM 카드와 리포트 생성 | 외부 서비스 최초 호출 전 | 처리위탁, 제3자 제공과 국외 이전 가능성 고지 | 부분 대응 | 업체명, 국가, 연락처, 전송 시기와 방법, 보유기간, 자체 학습 여부를 처리방침과 기능 실행 전에 알려야 함 |
| 가명처리된 정보의 서비스 품질 개선 활용 동의 | 카드 평가, 리포트 평가, AI 모델 개선, 내부 평가셋 | 서비스 개선용 데이터 저장 전 | 기본 서비스와 구분된 추가 목적 이용, 선택 동의, 가명정보 처리 | 대응됨 | 원본과 추가정보 분리, 재식별 금지, 접근자 제한, 90일 만료 삭제가 필요함 |
| 선택 동의 거부 시 기본 서비스 이용 가능 | 학습 데이터 제공 여부 | 선택 동의 화면 | 선택 동의 거부를 이유로 기본 서비스 제공을 거부하는 문제 | 대응됨 | 거부 사용자의 데이터를 학습 데이터셋과 평가셋에 넣지 않도록 기술적으로 분리해야 함 |
| 면회 준비와 리포트 완료 알림 수신 동의 | 푸시 알림, 리포트 처리 완료 알림 | 알림 활성화 전 | 기기 토큰 처리와 선택 기능 거부권 고지 | 대응됨 | 알림 본문에 환자 이름, 건강정보, 전사와 리포트 내용을 포함하지 않아야 함 |

## 기능별 확인 위치

| 앱 흐름 | 확인할 동의 |
| --- | --- |
| 회원가입과 피보호자 초기 설정 | 서비스 제공을 위한 개인정보 처리, 건강 관련 민감정보 처리, 피보호자 동의 확인 |
| 이미지 등록과 분석 | 이미지 분석 기능 이용 시 필수 동의 |
| 대화 카드 생성과 선택 | 서비스 제공을 위한 개인정보 처리 |
| 면회 녹음 시작 | 서비스 제공을 위한 개인정보 처리, 피보호자 동의 확인 |
| STT와 화자 처리 | 서비스 제공을 위한 개인정보 처리 |
| 외부 STT와 LLM 호출 | 확정 업체의 처리위탁과 국외 이전 안내 |
| 리포트 생성과 보호자 평가 | 서비스 제공을 위한 개인정보 처리, 건강 관련 민감정보 처리 |
| AI 품질 평가와 공통 모델 개선 | 가명처리된 정보의 서비스 품질 개선 활용 |
| 푸시 알림 | 면회 준비와 리포트 완료 알림 수신 동의 |
| 스토리북 생성 | 서비스 제공을 위한 개인정보 처리 범위에서 생성 가능 여부 추가 검토 |

## 필수와 선택 판정

| 기능 | 판정 | 법적 근거와 적용 조건 |
| --- | --- | --- |
| 프로필 이미지와 VLM 분석 | 해당 기능 이용 시 필수 | 이미지 없이 직접 입력하는 경로를 제공하므로 전체 서비스 필수로 묶지 않음. 이미지 분석을 선택한 사용자에게는 분석에 필요한 처리를 기능 필수로 적용 |
| 외부 STT와 LLM | 해당 기능 이용 시 필수 가능 | 계약 이행에 반드시 필요한 최소 처리이고 업체가 새록의 지시에 따라서만 처리하는 수탁자일 때 가능. 업체와 위탁업무를 공개하고 국외 이전 요건을 충족해야 함 |
| 외부 업체의 자체 모델 학습 | 선택 또는 금지 | 새록의 기능 수행을 위한 처리위탁을 벗어나 업체 자체 목적으로 이용하면 별도 법적 근거가 필요하므로 필수 처리에 포함하지 않음 |
| 푸시 알림 | 선택 | 앱 안에서 결과를 확인할 수 있으므로 핵심 서비스 제공에 필수라고 보기 어려움. 알림 기능을 선택한 경우에만 기기 토큰 처리 |

## 현재 동의문으로 대응되지 않은 기능

| 기능 | 현재 문제 | 필요한 조치 |
| --- | --- | --- |
| 스토리북 실물 제작과 판매 | 인쇄업체 제공, 사진과 이야기의 저작권, 배송정보 처리가 없음 | 상업화 결정 후 별도 동의, 위탁 문서와 판매 정책 마련 |
| 연구 발표와 외부 평가 데이터 제공 | 내부 품질 개선 범위를 넘어서는 이용임 | 별도의 선택 동의와 IRB 검토 여부 확인 |

## 관련 법적 근거

- 개인정보 보호법 제15조: 개인정보 수집과 이용의 법적 근거
- 개인정보 보호법 제16조: 목적에 필요한 최소한의 개인정보 수집
- 개인정보 보호법 제22조: 동의 항목 구분과 선택 동의 거부에 따른 서비스 거부 제한
- 개인정보 보호법 제23조: 건강 관련 민감정보의 별도 동의
- 개인정보 보호법 제28조의2: 과학적 연구 등을 위한 가명정보 처리
- 개인정보 보호법 제28조의4: 가명정보 안전조치, 처리기간과 기록 관리
- 개인정보 보호법 제28조의5: 재식별 목적의 처리 금지
- 개인정보 보호법 제26조: 개인정보 처리업무 위탁 계약, 수탁자 공개와 관리 감독
- 개인정보 보호법 제28조의8: 개인정보 국외 이전의 근거와 고지사항
- 통신비밀보호법 제3조: 공개되지 않은 타인 간 대화의 녹음 제한
