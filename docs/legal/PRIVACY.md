# 새록 개인정보 처리방침

시행일: 2026.10.20

새록새록 팀(이하 "새록")은 보호자의 면회 대화 준비와 기록을 돕는 모바일 앱 "새록"(이하 "서비스")을 운영합니다. 새록은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 문의를 신속하게 처리하기 위해 다음과 같이 개인정보 처리방침을 둡니다.

새록은 의료 진단, 병세 예측, 치료나 기억 회복을 제공하지 않습니다. 서비스가 처리하는 건강 관련 정보는 대화 질문을 알맞게 구성하는 데만 사용합니다.

## 1. 처리 목적

새록은 다음 목적에 필요한 범위에서만 개인정보를 처리하며, 목적이 바뀌면 미리 알리고 필요한 동의를 받습니다.

| 목적 | 내용 |
| --- | --- |
| 회원 관리 | 구글 로그인을 통한 본인 식별, 계정 생성과 유지, 로그아웃과 탈퇴 처리, 동의 이력 관리 |
| 피보호자 프로필 관리 | 보호자가 입력한 피보호자 정보와 확인된 생애 이야기의 저장과 조회 |
| 대화 카드 생성 | 면회 전 대화 소재와 질문 카드 생성 |
| 면회 기록과 리포트 | 면회 녹음의 음성 인식(STT), 보호자 소감 저장, 회차별 리포트와 변경 제안 생성 |
| 사진 보관과 분석(선택) | 등록한 사진의 보관과 표시, 동의한 경우 사진 설명과 대화 소재 후보 생성 |
| 서비스 품질 개선(선택) | 가명처리한 정보로 대화 카드와 리포트 품질 평가 |
| 알림(선택) | 면회 준비와 리포트 완료 알림 발송 |

## 2. 처리하는 개인정보 항목

### 가. 보호자(앱 이용자)

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 필수 | 구글 계정 식별자(`sub`), 내부 계정 식별자, 앱에서 사용할 호칭 | 구글 로그인, 가입 화면 입력 |
| 필수 | 동의 항목, 동의 문서 버전, 동의 여부와 시각 | 가입 화면 |
| 필수 | 면회 소감(만족도, 반응, 메모), 면회 녹음 속 보호자의 음성 | 앱 입력, 녹음 |
| 선택 | 알림용 기기 토큰과 알림 설정 | 알림 동의 시 |
| 선택 | 탈퇴 사유(계정과 연결하지 않음) | 탈퇴 화면 |

새록은 구글 로그인에서 받은 ID 토큰을 검증에만 사용하며 저장하지 않습니다. 이메일 주소와 구글 계정 이름은 저장하지 않습니다.

### 나. 피보호자(보호자가 입력하는 정보)

| 구분 | 항목 |
| --- | --- |
| 일반 정보 | 이름, 성별, 생년월일, 직업, 고향, 취미, 가족 관계 등 보호자가 입력한 생애 정보와 취향 |
| 건강 관련 민감정보 | 인지 상태 단계(경도인지장애, 경도 치매, 모름), 증상과 대화 시 주의사항 메모, 발화 분석 결과 |
| 면회 기록 | 면회 녹음 속 음성, 전사 결과, 리포트, 보호자가 승인한 이야기 |
| 사진(선택) | 등록한 사진, 사진 설명, 사진과 프로필 또는 면회의 연결 정보 |

피보호자 정보를 처음 입력하기 전에, 보호자는 피보호자 본인의 동의를 확인해야 합니다. 대리인이 동의하는 경우 적법한 대리 권한이 있어야 합니다. 보호자라는 관계만으로 대리 권한이 생기지는 않습니다.

### 다. 자동으로 수집되는 정보

새록은 광고 식별자를 수집하지 않으며, 제3자 분석 도구나 광고 SDK를 사용하지 않습니다. 서버는 보안과 장애 대응에 필요한 접속 기록(요청 시각, 결과 코드 등)을 남길 수 있습니다. 이 기록에는 음성, 전사 내용, 프로필 내용을 남기지 않습니다.

## 3. 처리 및 보유 기간

| 항목 | 보유 기간 |
| --- | --- |
| 계정 식별자와 동의 이력 | 회원 탈퇴(계정 삭제) 완료 시까지 |
| 피보호자 프로필, 생애 이야기, 대화 카드, 면회 기록과 리포트 | 해당 프로필 삭제 또는 회원 탈퇴 시까지 |
| 면회 녹음 원본 | 음성 인식 완료 후 즉시 삭제. 실패하거나 중단되어도 서버 업로드 후 최대 24시간 이내 삭제 |
| 등록 사진 | 사진 삭제, 사진 보관 동의 철회, 프로필 삭제 또는 회원 탈퇴 시까지 |
| AI 분석용 사진 임시 사본 | 분석 완료 후 즉시 삭제. 실패하거나 중단되어도 최초 생성 후 최대 24시간 이내 삭제 |
| 가명처리한 품질 개선용 정보 | 수집일로부터 최대 90일, 동의 철회 시 지체 없이 삭제 |
| 알림용 기기 토큰 | 알림 동의 철회, 로그아웃 또는 회원 탈퇴 시까지 |
| 로그아웃·탈퇴한 세션의 폐기 기록 | 해당 세션 토큰의 만료 시각까지 (개인정보를 포함하지 않음) |

다른 법령에 따라 보존해야 하는 정보가 있으면, 그 근거와 기간을 알리고 다른 정보와 분리해 보관합니다. 

## 4. 파기 절차와 방법

보유 기간이 끝나거나 처리 목적을 달성하면 지체 없이 파기합니다.

- 전자 파일과 데이터베이스 기록은 복구할 수 없는 방법으로 삭제합니다.
- 회원 탈퇴 시 계정과 연결된 서버 기록(프로필, 생애 이야기, 대화 카드, 면회 기록, 리포트, 사진 정보)을 함께 삭제합니다. 저장소에 보관한 사진 파일은 삭제 대기열을 거쳐 삭제합니다.

## 5. 개인정보의 제3자 제공

새록은 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우는 예외로 합니다.

구글 로그인 과정에서 새록이 구글로부터 계정 식별자를 받지만, 새록이 보유한 프로필, 음성, 사진, 전사문, 면회 기록과 리포트를 구글에 보내지 않습니다.

## 6. 개인정보 처리위탁과 국외 이전

### 가. 처리위탁

새록은 서비스 제공을 위해 다음과 같이 개인정보 처리를 위탁합니다.

| 수탁자 | 위탁 업무 | 처리 항목 | 처리 위치 |
| --- | --- | --- | --- |
| Amazon Web Services | 서버 운영, 녹음 원본 임시 저장, 등록 사진 보관 | 서비스 이용 중 생성되는 정보 전체 | 대한민국(서울 리전) |
| (주)엘리스그룹 (ML API) | 대화 카드, 리포트, 사진 설명 생성을 위한 AI 모델 호출 | 피보호자의 연령대, 생애 이야기와 취향, 전사 결과, 보호자 소감, 분석 동의한 사진 | 국외 서버에서 처리될 수 있음(아래 나.) |

(주)엘리스그룹은 위탁 업무를 처리하기 위해 Cloudflare, Inc.를 거쳐 요청을 받고, AI 모델 제공사의 API로 전달합니다.

AI 생성 요청에는 프로필의 이름, 성별, 생년월일 항목을 보내지 않습니다.

### 나. 국외 이전

AI 응답 생성 요청은 모델 제공사의 국외 서버에서 처리될 수 있습니다. 이 이전은 서비스 제공 계약을 이행하는 데 필요한 처리위탁이며, 「개인정보 보호법」 제28조의8에 따라 다음 사항을 알립니다.

| 구분 | 내용 |
| --- | --- |
| 이전받는 자 | (주)엘리스그룹 ML API에 연결된 AI 모델 제공사 |
| 이전 항목 | 피보호자의 연령대, 생애 이야기와 취향, 전사 결과, 보호자 소감, 분석 동의한 사진 |
| 이전 시기와 방법 | 대화 카드, 리포트, 사진 설명을 생성할 때마다 암호화된 네트워크(HTTPS)로 전송 |
| 이용 목적 | 대화 카드, 리포트, 사진 설명 생성 |
| 보유 및 이용 기간 | 요청과 응답을 저장하지 않으며, 응답을 생성한 뒤 처리를 끝냄 |
| 거부 방법과 효과 | 개인정보 보호책임자에게 요청하거나 회원 탈퇴로 거부할 수 있음. 거부하면 대화 카드와 리포트를 이용할 수 없음. 사진은 AI 사진 분석 동의를 철회하면 전송하지 않음 |

### 다. 요청 내용의 보관과 학습

- (주)엘리스그룹과 모델 제공사는 요청 내용과 응답을 저장하지 않습니다. (주)엘리스그룹은 과금을 위해 호출 시각, 토큰 사용량, 계정 ID만 남기며, 이 기록에는 요청 내용이 포함되지 않습니다.
- (주)엘리스그룹은 데이터를 보관하지 않는 모델 엔드포인트로만 요청을 전달합니다. 따라서 모델 제공사는 요청 내용을 저장하거나 모델 학습에 사용하지 않습니다.

## 7. 민감정보 처리

새록은 피보호자에게 알맞은 질문을 구성하고 부적절한 질문을 막기 위해, 별도 동의를 받아 건강 관련 정보(인지 상태 단계, 대화 시 주의사항, 발화 분석 결과)를 처리합니다. 이 정보는 진단이나 병세 판단에 사용하지 않습니다.

## 8. 가명정보 처리

서비스 품질 개선에 선택 동의한 경우에만, 가명처리한 정보(프로필 소재, 전사 일부, 발화 지표, 카드 반응, 보호자 평가)를 대화 카드와 리포트 품질 평가에 사용합니다. 이름, 연락처, 시설명, 상세 주소와 원본 음성은 포함하지 않으며, 재식별을 시도하지 않습니다. 동의하지 않아도 기본 서비스를 이용할 수 있습니다.
