# 개인정보 처리 동의안

상태: 사진 보관과 AI 분석의 가입 시 선택 동의 및 계정별 저장은 2026-10-14 PM 확정, 동의 화면과 서버 연결 및 외부 업체 정보 확인 필요

구글 로그인 관련 계정 관리 항목, 이메일과 이름의 미저장, 계정 생성 시점과 보유 기간은 PM 제안을 반영한 문구 초안이다. BE와 FE 검토 후 확정하며, 현재 적용된 정책이나 구현을 뜻하지 않는다.

2026-10-05 사진 등록과 AI 분석을 구분한 문구는 PR #92로 병합했다. 2026-10-14 PM이 사진 서버 보관과 AI 분석을 가입 화면의 별도 선택 항목으로 받고, 두 항목을 기존 계정 동의 이력에 저장하도록 정했다. 이미 유효하게 동의한 항목은 다시 묻지 않으며, 미동의자가 해당 기능을 사용하려고 할 때만 필요한 동의를 요청한다. [ADR-001](../architecture/decisions/ADR-001-consent-and-temporary-processing.md#등록-사진과-분석용-임시-사본의-구분)의 기준을 반영하며, 실제 동의 화면과 철회 및 삭제 기능은 후속 구현과 검증이 필요하다. 사진 속 정보주체의 동의 또는 적법한 대리 권한 등 처리 근거도 확인해야 한다.

새록은 맞춤형 대화 카드와 면회 리포트를 제공하기 위해 필요한 정보만 처리합니다.

가입 화면에는 필수 2개(서비스 개인정보 처리, 건강 관련 민감정보 처리)와 선택 4개(사진 서버 보관, AI 이미지 분석, 서비스 품질 개선, 알림 수신)를 함께 표시한다. 아래 피보호자 최초 등록 전 확인은 가입 화면의 항목이 아니다. 휴대폰 사진 선택과 카메라 및 마이크 접근도 기능 사용 시 처리하며 가입 동의로 대신하지 않는다.

☐ 전체 동의

항목별 선택을 유지하며 선택 동의를 거부해도 가입할 수 있다. 전체 동의는 가입 화면에 표시한 항목에만 적용한다.

## 가입 시 필수 동의

☐ [필수] 맞춤형 대화 카드와 면회 리포트 제공을 위한 개인정보 처리에 동의합니다.

- 목적: 회원 관리, 피보호자 프로필 관리, 맞춤형 대화 카드 생성, 음성 분석과 회차별 리포트 제공
- 계정 관리 항목: 내부 계정 식별자, 인증 제공자, 구글 계정 식별자(`sub`), 동의 종류, 버전, 상태와 시각
- 서비스 항목: 보호자의 이름 또는 별칭, 피보호자의 별칭, 연령대, 보호자와의 관계, 취향, 생애정보, 면회 기록, 보호자와 피보호자의 음성, 전사 결과와 발화 지표
- 구글 정보 처리: 구글 로그인에서 받은 ID 토큰은 계정 식별자를 검증한 뒤 저장하지 않습니다. 이메일과 구글 계정 이름은 현재 로그인 목적에 사용하거나 영구 저장하지 않습니다. 실제 구현에서 반환되는 경우 로그인 처리 후 폐기합니다.
- 처리 방식 검토안: 녹음 파일을 암호화하여 서버에 임시 저장할 수 있음
- 보유 기간: 계정 식별자와 동의 이력은 회원 탈퇴 또는 계정 삭제 완료 시까지, 프로필 정보는 프로필 또는 계정 삭제 요청 시까지, 녹음 원본은 분석 완료 후 즉시 삭제하며 최대 24시간
- 계정 생성: 구글 인증 후 필수 동의를 완료하면 계정 식별자와 동의 이력을 서버에 함께 저장합니다. 동의하지 않으면 영구 계정을 만들지 않습니다.
- 동의하지 않으면 맞춤형 대화 카드, 녹음 분석과 자동 리포트를 이용할 수 없습니다.

☐ [필수] 건강 관련 민감정보 처리에 동의합니다.

- 목적: 피보호자에게 적합한 질문 구성, 부적절한 질문 방지
- 항목: 인지 상태, 대화 시 주의사항, 발화 분석 결과
- 보유 기간: 회원 탈퇴 또는 피보호자 프로필 삭제 시까지
- 동의하지 않으면 맞춤형 대화 카드와 리포트를 이용할 수 없습니다.

## 가입 시 선택 동의

### 사진 등록과 보관

표시 및 저장 기준: 가입 화면에서 사진 보관과 AI 분석을 별도 선택 항목으로 표시하고, 기존 계정 동의 이력에 각각 버전과 시각을 저장한다. 유효한 동의가 있으면 사진이나 프로필을 추가할 때 다시 묻지 않는다. 미동의, 철회 또는 기록이 없는 계정이 해당 기능을 사용하려고 할 때 필요한 동의를 요청한다. 기존 계정은 자동 동의 처리하지 않는다. DB와 API 확장은 후속 구현이다.

☐ [선택] 등록한 사진을 서버에 저장하여 앨범, 일대기와 면회 기록에 표시하는 데 동의합니다.

- 목적: 등록한 사진을 보관하고 앨범, 일대기와 면회 기록에서 다시 보기
- 항목: 등록 사진, 사진 식별자와 프로필 또는 면회 연결정보
- 처리 방식: 비공개 서버 저장소에 암호화하여 보관. 이 동의만으로 AI 분석을 실행하지 않음
- 보유 기간: 해당 사진 삭제, 사진 보관 동의 철회, 프로필 삭제 또는 회원탈퇴 시까지. 보관 목적이 먼저 종료되어 불필요해지면 그때 지체 없이 삭제합니다.
- 동의하지 않아도 가입과 사진 없는 기본 서비스를 이용할 수 있습니다. 나중에 사진 업로드를 원하면 보관 동의를 받습니다.
- 같은 동의 범위가 유지되는 동안에는 사진을 올릴 때마다 다시 동의하지 않아도 됩니다. 보관 동의를 철회한 뒤 다시 사진을 올리려면 동의를 다시 받습니다.
- 이 동의는 사진 보관에 대한 동의이며 AI 분석 동의는 별도로 확인합니다.

### AI 이미지 분석

☐ [선택] 분석을 요청한 사진을 AI가 처리하여 사진 설명과 대화 소재 후보를 만드는 데 동의합니다.

- 목적: 이미지 속 인물, 사물, 상황과 글자를 분석하여 프로필과 대화 소재 후보 생성
- 항목: 분석을 요청한 사진, 사진에서 추출한 사물, 상황, 글자와 이야기 소재 후보
- 처리 방식: 분석 동의를 확인한 사진만 처리하며, AI 설명은 보호자가 확인하기 전까지 사실로 반영하지 않음
- 임시 사본 보유 기간: 처리 완료 후 즉시 삭제하며 실패나 중단 시에도 해당 작업의 최초 임시 사본 생성부터 최대 24시간 이내 삭제합니다. 재시도로 기한을 연장하지 않습니다. 별도로 등록한 사진 원본은 위 사진 보관 동의의 기간을 따릅니다.
- 사용자가 확인한 이야기 소재의 보유 기간: 기존과 같이 프로필 삭제 시까지 보관합니다.
- 동의하지 않아도 가입과 사진 없는 기본 서비스를 이용할 수 있습니다. 보관에 동의한 사진은 분석 없이 저장할 수 있습니다. 나중에 AI 분석을 원하면 분석 동의를 받습니다.
- 가입 때 분석에 동의했고 같은 목적과 범위가 유지되면 사진마다 다시 묻지 않습니다. 철회 후 분석을 다시 사용하려면 동의를 다시 받습니다.
- 분석 동의를 철회하면 분석을 중단하고 분석용 임시 사본을 삭제합니다. 등록 사진은 별도로 동의받은 보관 목적이 유지되는 경우에만 보관합니다.

문안 적용 전 확인: 미확인 분석 결과의 보관 및 철회 시 처리 기준, EXIF 등 메타데이터의 구체적인 처리 항목은 별도로 정해야 한다. 사용자가 확인한 이야기 소재의 기존 보유 기준은 이번 변경으로 바꾸지 않는다. 이 초안으로 수집 범위를 추가 승인하지 않으며, 필요한 항목과 기간을 확정해 동의 문구에 반영하기 전에는 실제 사용자 사진 분석에 적용하지 않는다. 기존 24시간 삭제 동의를 받은 자료의 보유기간을 이 문안만으로 늘리지 않는다. 법령상 별도 보존 의무가 확인된 항목은 근거와 기간을 알리고 분리 보관한다.

### 서비스 품질 개선

☐ [선택] 새록이 더 나은 대화 카드와 리포트를 제공할 수 있도록, 가명처리된 정보를 서비스 품질 개선에 활용하는 것에 동의합니다.

- 목적: 대화 카드와 리포트 품질 평가, AI 모델 개선
- 항목: 가명처리된 프로필 소재, 전사 일부, 발화 지표, 카드 반응과 보호자 평가
- 제외 항목: 이름, 연락처, 시설명, 상세 주소, 원본 음성
- 보유 기간: 수집일로부터 최대 90일
- 동의하지 않아도 기본 서비스를 이용할 수 있습니다.
- 동의를 철회하면 이후 개선 작업에는 사용하지 않으며, 보관 중인 정보는 지체 없이 삭제합니다.

### 알림 수신

☐ [선택] 면회 준비와 리포트 완료 알림을 받는 것에 동의합니다.

- 목적: 면회 준비와 리포트 처리 완료 알림 제공
- 항목: 앱 기기 토큰, 알림 설정, 알림 발송 기록
- 알림 내용: 환자 이름, 건강정보, 전사 내용과 리포트 세부내용을 포함하지 않음
- 보유 기간: 알림 동의 철회, 로그아웃 또는 회원 탈퇴 시까지
- 동의하지 않아도 앱에서 카드와 리포트를 직접 확인할 수 있습니다.

## 피보호자 최초 등록 전 확인

2026-10-14 PM 문서 수정안: 아래 확인은 가입 동의와 구분해 해당 피보호자의 최초 정보 입력 전에 진행하며, 매회 녹음 전 같은 체크박스를 다시 요구하지 않는다. 확인 방법과 대리 권한 기록의 구현은 후속 설계다. 상세 기준은 [ADR-001](../architecture/decisions/ADR-001-consent-and-temporary-processing.md#녹음-동의-확인-시점)을 따른다.

☐ [필수, 피보호자 등록 시] 등록할 피보호자에게 정보 처리와 녹음 내용을 안내했으며 동의를 확인했습니다.

- 동의자: 피보호자 본인 또는 적법한 대리 권한이 확인된 대리인
- 보호자라는 관계만으로 피보호자를 대신해 동의할 권한이 생기는 것은 아닙니다.
- 녹음 중 제3자가 참여하는 경우 녹음을 중단하거나 별도 동의를 받겠습니다.

문안 적용 전 확인: 현재 가입 API는 `serviceData`, `sensitiveData` 두 필수 동의와 기존 선택 동의 두 항목을 저장한다. 사진 보관 및 AI 분석 동의는 아직 없고, 프로필 API에도 위 확인과 대리 권한을 기록하는 항목이 없다. 이 문구를 표시하거나 녹음 버튼을 눌렀다는 이유만으로 필요한 동의를 확보했다고 처리하지 않는다. 동의 철회, 대상과 처리 범위 변경 시 재확인 및 작업 차단은 테스트 자료로 개발을 진행하되 실제 사용자 자료 사용 전에 검토하고 검증한다. 이번 수정은 기존 보유기간과 삭제 시점을 바꾸지 않는다.

## 외부 처리 안내

외부 STT 또는 LLM 사용이 확정되면 업체명, 처리 목적, 전송 항목, 처리 국가, 전송 시기와 방법, 보유기간, 자체 학습 여부를 개인정보 처리방침과 기능 실행 전에 안내합니다. 해당 업체가 새록의 지시에 따라서만 처리하고 계약 이행에 필요한 경우에만 기능 필수 처리로 사용합니다.
