# 법률과 개인정보 검토

관리: 주 PM 김영석, 부 PM 이예은

이 문서는 법률 자문이 아니라 검토 항목과 결정 이력을 관리하는 입구다. 법적 해석은 최신 법령, 공식 지침과 필요한 경우 외부 전문가 확인 후 확정한다.

## 문서 상태

| 문서 | 상태 | 내용 |
| --- | --- | --- |
| `README.md` | 운영 중 | 확정 원칙, 데이터 흐름과 열린 쟁점 |
| `consent-draft.md` | 동의 구조 확정, 외부 업체 정보 미정 | 필수 동의, 선택 동의와 가명정보 활용 문구 |
| `consent-mapping.md` | 운영 중 | 동의 문구별 기능, 법적 쟁점, 대응 수준과 남은 조건 |

동의 구조와 서버 임시 처리의 경계는 `ADR-001-consent-and-temporary-processing.md`에 기록한다. 외부 STT와 LLM 관련 문구는 업체 정보와 처리 조건이 확정된 뒤 완성한다.

## 현재 확정된 데이터 원칙

- 프로필, 전사문과 회차 기록은 사용자 단말 저장을 기본으로 함
- 녹음 원본과 이미지 원본은 사용자가 동의한 기능 수행에 필요한 경우 암호화하여 서버에 임시 저장할 수 있으며 처리 완료 후 즉시 삭제하고 최대 24시간을 넘기지 않음
- 직접 식별정보는 외부 AI 요청에서 제외함
- 실제 사용자 자료와 마스킹한 실제 자료를 GitHub에 저장하지 않음
- 실제 사용자 정보와 전사 내용을 로그와 원격 분석에 남기지 않음
- 필수 동의는 서비스 제공을 위한 개인정보 처리, 건강 관련 민감정보 처리, 피보호자 동의 확인의 세 항목으로 운영
- 이미지 분석은 기능 이용 시 별도로 동의를 확인함
- 서비스 품질 개선용 가명정보 활용과 푸시 알림은 선택 동의로 운영
- AI 제안은 사용자 확인 전 프로필과 스토리북에 반영하지 않음

## 현재 데이터 흐름

    필수 동의와 피보호자 동의 확인
    → 단말 녹음
    → 단말 처리 또는 동의 범위의 서버 임시 처리
    → 관찰값과 이야기 후보 생성
    → 보호자 확인
    → 단말 프로필과 이야기 반영

외부 STT와 LLM 업체는 확정되지 않았다. 도입 전 업체명, 국가, 처리 목적, 항목, 보유기간, 자체 학습 여부와 국외 이전 근거를 문서화한다.

## 열린 쟁점

- 피보호자 본인의 녹음 동의 방법
- 의사결정 능력이 부족한 피보호자의 동의 처리
- 보호자 동의만으로 가능한 범위
- 요양시설의 녹음 허가 필요 여부
- 제3자의 목소리가 함께 녹음된 경우
- 음성과 화자 특징의 개인정보 해당 여부
- 마스킹한 전사문의 가명정보 해당 여부
- 서버의 일시 처리와 외부 LLM 전달에 따른 의무
- 국외 이전과 처리위탁 여부
- 보관 기간, 삭제 절차와 삭제 증명
- 평가와 연구 목적의 데이터 재사용 가능 범위
- 진단과 치료 효과를 암시하는 표현의 위험
- 사진, 음악과 외부 자료의 저작권
- 스토리북을 피보호자에게 직접 제공할 때 필요한 동의와 안전 조치
- 스토리북을 실물 앨범으로 판매할 때 필요한 권리, 거래와 환불 조건

## 변경 기록 형식

법률과 개인정보 결정에는 다음 정보를 기록한다.

- 결정 번호와 날짜
- 상태: 검토 중, 확정, 폐기, 외부 확인 필요
- 데이터 항목과 처리 목적
- 저장 위치, 전송 대상과 보관 기간
- 삭제 방법과 접근 가능자
- 확인한 출처와 확인일
- 결정자와 재검토 조건

개인정보 이동 경로가 바뀌는 PR은 이 문서와 관련 ADR을 함께 갱신한다.
